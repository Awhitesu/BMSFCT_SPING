# 介绍

    │   └── OpteeQDLLx64.dll						// SG系列在线烧录器DLL文件（Win64位）

    │   └── libOpteeQ.so						// SG系列在线烧录器ELF文件（Linux）
    
    ├── File								// 参考文档
    
    │   └── SG400 User Manual.pdf					// 软件用户手册

    ├── Lic								// 芯片/通道授权许可文件

    │   └── SG series LIC Authorization Instruction Manual.pdf		// 更新、授权导入、芯片包导入流程说明
     
    ├── OpteeQ_Management_Tool_Setup.exe				// OpteeQ软件安装包（Windows）

    ├── OpteeQ_Management_Tool.zip					// OpteeQ软件安装包（Linux）

    ├── 力捷丰产品保修条款.pdf						// 力捷丰产品保修条款
