# ZLG CANFDNET-400U 空闲连接测试

日期：2026-10-19；IP：192.168.1.106；TCP 端口：8000。使用项目中的官方 x64 SDK 与实际 ZLGNetBus 驱动。

## 结果

- TCP 连接成功，初次探测耗时约 32 ms。
- 10 轮打开、四通道初始化、空闲接收、关闭全部通过；每轮均取得 CH1～CH4 四个通道句柄。
- 共 672 次 recv 调用，收到 0 帧，无异常。按当前没有外部报文的条件，0 帧不属于接收失败，但不能证明真实总线收发正常。
- 首次打开约 2912 ms，包含 Python 模块及原生 SDK 加载和初始化；后续重新打开约 34～52 ms。
- recv(0.05) 调用最长约 66 ms，包含 SDK 调用和系统调度；关闭最长约 19 ms。
- 12 项相关软件回归测试通过。

## 测试范围

每轮同时打开四个物理通道，默认选中通道在 CH1～CH4 间轮换；首轮接收约 15 秒，其他各轮约 3 秒。脚本未调用 CAN/CANFD 发送接口，也未调用动态波特率、终端电阻或持久化配置接口。SDK 客户端 IP、端口及回显选项用于建立本次连接，结束后关闭所有测试句柄。

本机 sys_config.json 中 zlg_enabled 和 zlg_sdk_enabled 均为 false。本轮绕开应用启用开关独立测试，没有修改配置文件。若在应用中使用，应按实际配方与硬件设置启用。

本轮仅验证短时连接、四通道句柄初始化、无报文接收轮询和资源释放。未连接对端或发送测试报文，因此尚未验证实际 CAN/CANFD 数据收发、波特率匹配、FD BRS、丢帧率、UDS 多帧通信及长时间负载稳定性。不能据此宣称这些功能全部验收通过。
