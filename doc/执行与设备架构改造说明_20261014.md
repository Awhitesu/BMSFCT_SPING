# 执行与设备架构改造说明

本次只修改源码，没有打包、上传 GitHub 或操作现场设备。

## 停止与收尾

- 界面停止入口仅设置取消状态并向执行线程发送停止请求，不执行设备通信，也不等待线程。
- 正在执行的动作结束或响应取消后，由原执行线程关闭输出、结束数据库记录和导出报告，避免清理与原动作并行。
- 收尾结束后才移除 worker 和资源占用；期间同通道不能重新启动。
- 软件退出先异步停止测试，待执行线程收尾后再断开设备及关闭数据库。
- 输出关闭异常会记录错误；不会因此跳过后续记录收尾或永久保留线程。

停止请求立即返回，不表示硬件动作能被立即中断。旧驱动仍须等当前通信调用的超时或返回；本次未统一改写所有驱动的协议超时，也未改变所有设备的输出安全策略。

## 共享板卡连接与通道映射

- 板卡分类调试、电阻卡组合调试及自动工步共用 DeviceManager 中的 RNBoard 实例，连接与协议事务锁随实例共享。
- 配置变更会在同一实例上断开旧连接并更新地址，避免其他页面继续持有旧实例。
- 调试页面关闭不再自行断开共享板卡；连接统一由设备管理器管理。
- 电阻卡设置及读取工步新增“全局通道（0使用原板号）”：填写 1–36 时使用与组合调试相同的序号映射；0 保留原来的板号／本板通道行为。未启用的通道报错。
- 本次共享连接与事务锁不等于整段测试的设备独占预约；同一设备手动调试与自动测试之间的完整会话级仲裁仍可继续扩展。

## 稳定身份与兼容

- 配方测试项和子工步增加 step_id，编辑保存保留身份；每次运行增加 execution_id。
- 老配方加载时补充并原子保存 ID；旧动作格式继续可读。
- 新设备动作保存 schema_version=2、稳定设备／动作／参数键，中文文字保留用于显示，不再参与新格式执行解析。
- 同名测试项的状态、测量值及监控恢复使用索引身份，执行结果同时按 step_id 保存。
- 数据库保留原表和历史记录，增加 execution_id、step_id、attempt，并新增 test_step_events 记录子工步事件及父项身份。

## 验证

回归验证覆盖：停止遇到阻塞动作时界面入口立即返回、清理顺序和执行线程、收尾期禁止重启、清理异常、同名结果隔离、中文显示文字变更兼容、共享板卡与配置更新、电阻卡序号映射、数据库迁移与结果保存、原工步分派、UDS、板卡协议、配方重命名和拖动、设备工步编辑。

这属于软件测试与模拟通信验证，尚未完成现场仪器的断网、停止及并发实机验证。
