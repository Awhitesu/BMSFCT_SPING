# 2026-10-21 更新说明

本次更新以 GitHub `9979652` 为基础，包含以下功能与修复。

## 工步编辑界面

- 修复首次新增与再次编辑时，一级分类、设备和动作字段整体右移的问题。
- 将“发送通道（可多选）”独立成整行，避免长标题撑宽全部标签列。
- 顶部字段标签统一左对齐；切换单通道和多通道时按整行隐藏。
- 修复读取电流选中后显示方块的问题。读取电压／电流统一采用圆环与绿色圆点，并保留单位切换逻辑。

## 电阻卡全局通道控制

- 最多6张电阻卡，每张固定6通道；已启用卡按设备序号排序后连续编号，最多CH36，未启用卡不占号。
- 设备设置页显示启用、配置编号、IP、端口、设备序号、通道数量、有效全局通道范围。
- 修改启用状态和设备序号时预览新范围，保存并应用后生效；Unit ID与协议参数保留在高级设置。
- 新增“设置阻值（全局通道）”和“读取设定阻值（全局通道）”工步。
- 支持单通道 `7`、多个通道 `1,7,13`、范围 `7-12`，以及“所有／所有奇数／所有偶数”。
- 批量选择覆盖已启用卡；指定未启用或不存在的通道、重复通道、非法范围时，在首次写入前拒绝执行。
- 全局通道映射由调试页和测试工步共用；原板号／本板通道的历史工步保留兼容。
- 单通道回读输出数值，多通道回读输出各通道与阻值；回读为板卡设定值，并非电气实测阻值。

注意：启用状态或设备排序变化会改变全局通道映射。保存后应根据设置页展示的有效范围核对配方通道。

## Easy320批量继电器控制

- “全部断开”调用按导入点位分组的批量写入和集中回读，取代每点分别固定等待的旧路径。
- 连续地址使用Modbus FC15（0x0F）写入，不填补导入表中的地址空档，避免操作未配置点位。
- 24个连续点位的正常路径为一次写入、50ms等待、一次回读；实际端到端耗时取决于PLC与网络。
- 只有明确收到“不支持功能码”时才回退到原逐点写入与回读方式。
- 超时、异常、回读长度不足或状态不一致均判失败，不绕过确认。
