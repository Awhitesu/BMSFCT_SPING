# 回读等待进入范围

在数值回读工步中勾选“等待回读进入范围”，填写上下限、最长等待秒数、读取周期秒数和连续合格次数。默认不勾选，原有单次读取逻辑不变。上下限包含边界，按回读所选单位（未提供单位选择的设备按其原生单位）填写。测试项自身上下限仍独立生效，应保持一致。

立即进行第一次读取。每次读取返回后按所填周期等待下一次；连续达到范围要求即提前通过。越界读数使连续计数归零；超时、通信失败或无效数值使工步失败。日志记录每次读数、范围、连续次数和耗时，只有最后成功读数进入工步结果。现有失败停止/忽略继续/重试策略仍生效，重试会开始新一轮等待。

支持传统电源、模拟器和CA550数值回读，以及设备工步的数值测量。输出状态和波形文件等非数值动作不提供该选项。配置放在原工步参数内，不需要升级配方结构。

周期表示单次读取完成后的等待间隔，并非固定采样频率；实际速度受仪器响应影响。最长等待不覆盖驱动自身通信超时。取消会立即中断周期等待，正在进行的同步仪器读取仍需返回或通信超时；在超时或取消后返回的读数不会误判通过。

验证 logs/read_until_final：轮询时序、连续计数重置、超时无多余读取、取消、通信失败、迟到读数、配置校验和保存回读、执行引擎最终结果收集，并联合设备工步及结果回归。全量测试尝试在既有 test_preparation_is_async_and_cancel_does_not_start_run 启动准备测试处等待，不能视为全量通过。
