# 设备页面重叠风险检查

## 已确认原因

IT6722A 页面把连接参数、九行控制/确认信息、实时读数放在不滚动的纵向容器里。连接后确认文本变长、自动换行，内容需要的高度增加；在嵌套设备分页或较大字体下，可用高度不足，布局压缩会造成输入框、固定高度按钮及文字交叠。不是连接通信本身把控件坐标改乱。

NGI 高压源使用相同结构，存在同类风险，已同步采用滚动容器、内容最小尺寸约束、44 像素控制行及明确间距。长确认文本可换行，空间不足滚动显示，不压缩控制行。

## 离线检查范围

不连接仪器，实际构造 HVSourceTab、MainboardPowerTab、IT6333BTab、MultimeterTab、DG2052Tab、TBS2102BTab。使用项目样式、12 点字体，在 1000×480 和 1400×700 两种页面尺寸下显示并处理布局事件。两个电源页注入六倍长的确认文本，逐一验证电压、电流、输出按钮、超时、容差、状态、确认、统计控件上下不交叉。两页验证通过。

IT6333B、万用表、DG2052 通道页、示波器子页已有滚动容器，完成上述构造和尺寸检查，未发现与本次电源页相同的无滚动多行控制布局。尚未给这些页注入各仪器所有可能的回读数据，不能宣称所有连接后布局均已验收。

静态检查还发现 SG400、瑞萨 E2 顶部含较多横向连接字段、工程按钮及审计字段，缺少整页滚动保护；较窄窗口、长工程路径/芯片信息下有横向挤压风险，尚未在本轮复现具体重叠，不作为已确认缺陷。CA550、EASY320 已有滚动区域；板卡、CAN、模拟器也需要分别验证表格、动态通道和长异常消息，不能仅凭未连接时正常认定连接后正常。

## 边界

本轮只修改高压源页布局，不修改连接、设压、设流或输出控制逻辑；不连接真实设备、不操作输出。离线布局检查可提前排除大量显示缺陷，协议响应、实测值及硬件时序仍须实机确认。
