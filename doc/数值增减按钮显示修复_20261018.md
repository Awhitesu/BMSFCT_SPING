# 数值增减按钮显示修复

问题：全局样式设置了数值框的增减按钮背景及边框，但未指定图标，导致部分主题下原生箭头消失，只剩空白按钮区域。

修改：

- 为数值输入框统一指定SVG加号与减号，上方增加、下方减少。
- 正常状态使用浅色图形，禁用/到达边界时使用灰色图形。
- 增减区宽28像素，增加中线和左右边界，提供悬停及按下反馈。
- 保留输入值空间，不改变数值范围、步长及已有滚轮防误触行为。
- 样式资源加载时转为基于源码/打包资源目录的绝对路径，避免不同启动目录导致SVG缺失。

新增测试`tests/test_spin_button_visibility.py`验证整数框、浮点框的增减区域、像素可见性、加减点击、禁用行为以及从其他工作目录加载图标。与原有布局约束测试一起定向验证通过。
