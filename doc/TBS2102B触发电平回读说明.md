# TBS2102B 触发电平设置与回读

触发设置页保留输入的请求值；应用完成后显示仪器实际回读值及偏差。实际值不同会明确提示。边沿和脉宽读取触发电平，欠幅读取上下阈值；LINE 来源不设置通道电压阈值。

## 资料依据

- [泰克 TBS2000B 数据手册](https://www.tek.com/en/datasheet/digital-storage-oscilloscope-tbs2000b-series-datasheet)：输入通道触发范围为屏幕中心上下 4.90 格。
- [泰克编程手册](https://download.tek.com/manual/TBS2000-TBS2000B-Programmer-077114903.pdf)：`TRIGger:A:LEVel:CH<x>` 设置电平，带问号回读电平；每个通道独立。欠幅使用 `LOWerthreshold`、`UPPerthreshold`。

## 本机实测（2026-10-13）

TBS2102B，固件 v1.32.147，CH1，探头倍率 10，垂直位置 0：

| V/div | 请求电平 | 仪器回读 |
|---|---|---|
| 1 | 1.650V | 1.640V |
| 1 | 1.660V | 1.680V |
| 0.1 | 1.650V | 0.496V |

1V/div 时附近量化间隔实测约 40mV，此值不是所有刻度的固定规格。0.1V/div 时，位置 0 下的触发范围约 ±0.49V，无法覆盖 1.65V。0.496V 是本机实际限幅回读，不应把公式估算当作准确回读。

## 怎么设置

先让目标电平处于当前刻度和垂直位置对应的触发范围内，再设置触发电平。位置 0 时，1.65V 至少需要约 0.337V/div 的范围；例如 0.5V/div 能覆盖该目标，但仍需检查量化后的回读值。精细观察某个直流电平附近信号时，需要合适的垂直位置；位置移动本身也受仪器限制。

软件不会擅自改变刻度、探头倍率或位置，也不会为了显示一致而覆盖用户输入。请求与回读不同应由实际测量需要判断是否可接受。
