# 测试前MES过站检查

入口：软件设置 → 测试前MES过站检查。默认关闭，需要MES校验的工位勾选启用，配置接口URL、设备/工站编号equipmentNo、可选工单号orderNo及超时后点击“保存MES过站设置”。保存后下一次扫码启动生效。沿用现有`moveInCheck`接口及MES响应解释规则；用户名使用当前登录账号。

## 启动流程

扫码确认 → 条码规则与序列有效性检查 → 后台MES过站检查 → 配方硬件参数应用 → 创建测试记录 → 启动测试序列。

启用时，每次启动都使用本次扫码SN重新请求，没有通过缓存。MES通过才继续；拒绝、超时、网络异常或配置错误均阻止测试，弹窗显示错误原因。检查失败不会作为产品测试NG计入良率，不会创建新的测试记录；员工需要重新扫码重试。

请求过程中使用现有测试准备任务，禁止重复启动和切换配置，不阻塞界面。员工停止或关闭窗口后，即使MES返回通过也不会继续启动；正在等待的HTTP请求依赖设置的超时结束，不强杀工作线程。

## 配置和追溯

新增持久化开关`mes_precheck_enabled`。复用`mes_url`、`mes_equipment_no`、`mes_order_no`、`mes_timeout`配置，与原MES调试页及MES工步共用接口参数。未保存的输入不会参与启动检查。

每次扫码启动前截取配置和登录用户名，避免等待过程中改变本次校验身份。启用状态、参数及MES通过结果进入测试配方快照；请求与判定信息显示在测试记录栏。未通过的原因保留在弹窗和当前界面记录栏。

原配方中已有MES工步仍然执行；本功能是全局启动前检查，不自动删除配方中的工步。现场启用前应核对是否还需要原来的重复校验。
