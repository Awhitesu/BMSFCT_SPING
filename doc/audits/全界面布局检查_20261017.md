# 全界面布局检查

## 方法和范围

工具 tools/layout_audit.py 使用临时数据库与内存配置、offscreen Qt，跳过实际设备自检，停止并拦截设备轮询计时器，不连接仪器、不发送输出指令，不修改现场配置。遍历主导航、全部设备分类页及各级子 TAB，实际显示并处理布局事件，记录可用尺寸、minimumSizeHint 和滚动容器数量。超出最小尺寸表示挤压风险，并不自动等同于控件已经重叠。

测试窗口 1024×700、1440×900、1920×1080，字体 10/12 点。九种自定义弹窗检查目标尺寸 640×480、1024×700；其自有最小尺寸可能使实际尺寸大于目标，清单保存实际值。覆盖登录、工步编辑、测试项编辑、批量编辑、条码规则、AI 配方、监控、账户、下载进度及弹窗内部 TAB。启动自检另外隔离检查：650×450，内容最小尺寸 354×155，未执行自检。

常规配置与最大通道配置分别运行清单。最大配置为六台模拟器各24通道、14块板卡全部启用，仅构造控件，不实际连接。硬件管理、CAN、板卡等表格自身已有滚动。操作系统通用文件选择器、QInputDialog/消息框的每一种临时组合未逐个自动打开，相关调用通过源码检查；不能宣称穷尽所有操作系统对话框及仪器返回内容。

## 本轮修复

1. 配方配置、EASY320、CAN/UDS、SG400、E2、APP刷写、MES、主测试页增加内容最小尺寸和滚动保护。保留原页面对象与成员，按钮、信号和业务入口不变。窗口不足时允许滚动到完整控件，而不是强行压缩。
2. 模拟器“量程与限流”子页增加相同保护。原“运行控制”已有滚动，不重复改造。
3. 账户弹窗从固定450×390改为可调整大小，默认520×540，避免新增账户/修改密码页高度不足；条码规则弹窗从固定760×680改为可调整大小，默认860×680。两者内容均增加滚动保护。
4. 主标题使用纯文本、可换行、可收缩宽度，避免标题的最小宽度挤压账户按钮；登录标题也使用纯文本换行。
5. 新增 ui/layout_safety.py 统一提供保护容器；不统一修改所有控件坐标或业务定时器。

## 结果

首轮主页面312组检查存在28条尺寸压力记录；补充递归到电源/下载内部TAB及主要弹窗后，共392组。常规配置最终392组无尺寸超限。加载中文字体、最大通道配置后又发现小窗口的主测试页和MES高度压力，已补充保护；最终最大配置392组也无尺寸超限。启动自检另行验证通过。两个电源页长确认信息的离线控件不交叉验证沿用上一轮结果。

记录：logs/layout_audit_20261017/inventory.json、logs/layout_audit_20261017_maximum/inventory.json，目录含主页面及弹窗截图。人工查看了小窗口主页面和账户页截图；并非每条清单都有逐像素视觉验收。

完整回归中先遇到旧测试将临时产物写入项目外固定个人目录而被拒绝，已将 tests/test_burn_recorder.py 的产物目录改为独立 TemporaryDirectory，保留测试断言；不扩大文件访问权限。旧可选OPJ样本仍按原测试逻辑读取/跳过。中间回归823项、244项子测试通过，44.38秒。最终结果见 logs/layout_release_20261017/。

## 使用和边界

最终完整回归：823项测试、244项子测试通过，39.58秒，进程退出码0。本轮未出现原生崩溃。

优先使用正常分辨率或最大化窗口。小窗口遇到内容过多时使用纵向/横向滚动查看；本次不是将所有密集控制区重新设计为响应式多列。

未验证所有厂家长错误串、所有DPI缩放比例、所有弹出键盘和实机通讯响应。离线布局可发现显示问题，不能替代设备协议和实际输出验收。本轮未打包、未上传。
