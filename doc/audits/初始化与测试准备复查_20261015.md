# 初始化与测试准备复查

修复范围：devices/manager.py、ui/tabs/overview_tab.py。

- 板卡创建从批量连接之前移入逐台连接循环。缺少 IP 等单块配置错误独立记录，不再阻止其他设备初始化；取消后不再提前修改板卡对象。

- 自动测试准备在 CAN 断开、配置完成之后再次检查取消，不再在这些阶段收到停止后继续重连。
