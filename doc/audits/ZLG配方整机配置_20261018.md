# CAN设备选择与ZLG配方整机配置

配方CAN卡选项收敛为PCAN_USBBUS1和ZLG CANFDNET-400U。ZLG是一个设备，包含四个物理通道；不再将它们列成四块卡。

用户切换到ZLG时弹出整机配置，可设置IPv4地址、TCP端口、发送/UDS通道，以及CH1–CH4各自的使能、仲裁波特率、数据波特率、120Ω终端电阻。速率限定为当前已实现动态接口支持的标准值；自定义位时序仍不提供。SDK目录沿用硬件管理中心。

“配置ZLG整机…”按钮可再次编辑。取消首次配置会返回PCAN；加载已有配方不会自动弹窗。编辑过程不连接设备，参数随配方保存。兼容原有ZLG_CAN1–4内部通道标识及旧配方；旧配方没有整机配置时沿用原有硬件管理网络参数，不凭空覆盖设备配置。

测试开始前，在后台连接配方指定的设备，并应用四通道参数。不写设备断电保存参数，避免每次测试持久化设备配置。配置调用失败则释放连接、阻止启动测试，不把部分生效当作成功。发送/UDS通道必须启用。其他启用通道保留驱动原有接收监听能力。

硬件管理及CAN调试中的通道选择只保留PCAN_USBBUS1和ZLG_CAN1–4，后者仍表示同一台设备的物理通道。移除PCAN_USBBUS2–16等选项和自动枚举重新追加它们的路径。

验证包含配方两类设备选择、选择ZLG弹窗、加载配方不弹窗、参数保存还原、禁用发送通道拒绝、整机下发及下发失败阻止启动。相关测试位于`tests/test_zlg_recipe_config.py`。
