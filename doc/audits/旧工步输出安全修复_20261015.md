# 旧工步输出安全修复

沿F11–F13检查高压源、IT6722A和CA550的旧式参数执行入口，新增 core/legacy_controls.py，统一解析、逐项确认和取消处理，驱动协议及底层回读确认继续复用原实现。

## 已复现并修复

- 高压源/IT6722A/CA550设置过程中取消，旧代码没有在开启前再次检查，可能继续发送开启命令。
- 设置抛出异常或参数非法时，明确的OFF可能被异常分支提前挡住。
- CA550归零抛异常时，OFF不能继续执行；部分设置失败也可能被后面的关闭成功覆盖。
- CA550使用宽松数字提取，NaN等非法输入可能被变成0并开启。
- CA550输出类型曾扫描整段参数，量程中的mA可能错误影响Type:V的功能选择。

## 当前行为

- 先完整解析参数，再发送设置；重复、冲突、无效输入明确失败。
- 每个设置操作之前及开启之前检查取消；设置失败不继续开启。
- 明确OFF独立尝试，不依赖前面的配置成功；归零和OFF分别收集错误，保留总体失败。
- 旧电源V/A数值和中文/英文开启关闭参数继续支持；CA550参数按字段解析，保留原量程码和功能码，不推测新的仪器协议。
- 旧工步不再把共享CA550连接的串口改成COM42，连接使用现有驱动配置。

新增 tests/test_legacy_output_safety.py，使用模拟驱动验证取消、设置异常、非法值、关闭失败、归零失败、有效设置及冲突参数。先复现高压源取消后仍返回成功，再修复。未操作现场输出，未打包或推送。

完整回归：729 passed、244 subtests passed，耗时37.96秒；修改文件静态检查通过。合作式取消不能撤回已经发送到仪器的命令，真实输出关闭仍须看驱动回读和实机确认。
