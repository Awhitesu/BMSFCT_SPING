# UDS 多段组合解析

在“数据解析”中勾选“多段组合”。段数自动按记录统计，不需要预先填写。

1. 在线抓取，或手输完整 UDS 响应样本。
2. 在字节块上拖选第一段，右键选择“追加为 HEX / ASCII / BCD / 数值计算 / 自定义公式”。
3. 重复拖选、右键追加，右侧分段表保留每一条记录；字节区使用对应颜色标记。
4. 按表格顺序组合输出。默认无分隔符；需要时填写拼接分隔符。
5. 保存当前服务序列行，再保存工步和配方。

例如前三字节 `01 02 03` 选 HEX，随后四字节 `41 42 43 44` 选 ASCII，再后两字节 `12 34` 选 BCD，输出为 `010203ABCD1234`。

手工配置时，填写“当前段解析格式”、起始字节偏移和长度，点击“追加当前段”。偏移从完整 UDS 响应 PDU 的第0字节开始；长度0表示到末尾。组合中的 HEX 段输出连续十六进制字符，保留前导零。

修改已有记录：点击分段表中的记录，参数载入编辑区，修改后点击“修改选中段”。可以删除、上移、下移。仅拖选新的范围不会覆盖已有记录。

组合输出用于额外期望结果比较、工步最终输出及所填结果变量。任意一段解析失败，整次组合失败，不输出不完整的结果。服务发送序列中仍由“最终输出”勾选框指定哪一行提供工步输出。

旧的单段配方保持单段模式；手动勾选多段组合时，已有单段规则会保留为第一段。曾经被旧版本覆盖、没有保存下来的早期选区无法恢复，需要重新添加。
