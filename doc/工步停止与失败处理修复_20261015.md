# 工步停止与失败处理修复

本轮检查自动化设备工步，不连接实物、不打包。

## 确认的问题及处理

1. IT6333B和DG2052配置工步，若前面的参数设置失败，就不会执行工步指定的OFF。现在仍尝试关闭输出，但保留原始配置失败，整步不会转为PASS。配置失败和关闭输出都失败时，两种原因同时记录。
2. 配置过程被停止后，旧逻辑仍可能继续设置下一参数或开启输出。现在执行前、取得设备锁后、连接后，以及多段配置操作之间和开启输出前检查停止状态。已接受的硬件指令无法撤回，正在进行的通信仍须结束；后续安全关闭由现有停止清理流程执行。
3. 板卡写入工步忽略驱动返回值，返回False/None也会直接PASS。现在检查失败返回；合法的0Ω数值回读不会被当作布尔False。
4. 示波器单次采集取消/超时时，若补发停止指令也失败，会掩盖最初错误。现在同时保留原始原因和停止采集失败原因。
5. 补充示波器触发实际回读的边界校验：NaN、Inf、布尔值不得通过容差比较或写入测量变量。

## 验证

新增 `tests/test_sequence_cancellation_failures.py`：配置失败的ON/OFF/KEEP三种行为、配置过程中停止、已停止的工步不访问设备、双重故障、无效触发回读、板卡失败返回。

补充引擎已停止时不得执行设备工步的集成测试。原示波器取消测试改为在采集启动后触发取消，另有独立用例验证启动前已停止时不发送任何指令。

最终全量回归：556项测试、244项子测试全部通过；本轮新增17项测试。本轮修改的源码和测试静态检查通过。
