# 持续 BUG 审查（2026-10-15）

本轮审查覆盖通信、自动序列、配置切换、停止退出、MES 和结果留存。已修改源码，未打包、未推送 GitHub，未操作真实仪器。

## 已确认并修复

- CAN：重连时旧接收线程可能读取新连接；发送调用返回前的快速应答可能被丢弃；消费缓存顺序破坏多帧顺序；断开不能及时唤醒等待；非法 DLC 和过长数据被静默接受；连接启动失败遗留总线句柄。现在隔离连接生命周期、串行请求、按接收顺序消费，并严格校验帧。
- UDS/ISO-TP：截断数据、错误 SID/DID/子功能/例程/块序号可能被接受；流控发送失败未中止；后续块 WAIT 和等待预算处理不完整。现在验证响应身份、完整性和流控，整笔请求共用通信锁。
- MES：HTTP 200、未知正文或冲突字段可能被误判为成功。现在必须有可识别的明确成功结论，失败字段不能被其他字段覆盖，超时必须为有限正数。
- 旧配方电池模拟器控制：HIGH 量程判断错误，设置失败后仍开启，非法电压可能变成 0，取消后仍执行后续开启。现在先校验参数、逐项确认，失败不再开启；明确关闭命令仍尽力执行。
- 安全关闭与配置：曾连接但失联的设备不能再被报告为已确认关闭；关断失败阻止替换配置；初始化返回失败不再显示全部连接成功。恢复失联设备配置时保留无法确认旧设备输出的提示。
- 结果数据库：完成写入超时后，迟到的 PASS 更新可能覆盖失败状态。现在补写 RECORD_ERROR；工作线程死亡且还有待写数据不能报告关闭成功；保留 NaN、无穷、布尔及字节等原始异常值，避免静默丢失。
- Excel：文本可能成为公式、控制字符中断导出、保存失败损坏已有报表。现在按文本保存、转义非法字符、临时文件完整保存后替换；主记录和明细使用一致读取快照。
- 配方文件：统一限制路径、保留名称及目录逃逸；不存在的同名重命名不再假成功。
- 登录与执行：兼容旧中文密码校验，限制损坏哈希的迭代次数；全跳过序列不能启动并产生 PASS；删除无消费者的无限日志副本。
- 退出：用户已明确选择仍然退出后，重复数据库关闭异常不再使其陷入无限弹窗。

## 验证

完整测试：643 passed，244 subtests passed。新增四组回归文件覆盖上述失败、取消、重连、并发和持久化情况。测试使用模拟通信、临时数据库和 Qt 离屏环境。

另完成两轮独立进程完整复跑，均为 643 passed、244 subtests passed，未出现原生崩溃。结果记录于 `logs/qt_audit_final_20261015`，每次包含完整测试和原生崩溃跟踪。

## 验证边界

- 没有真实硬件和实际 MES 服务的联调证据。设备失联后，软件无法证明物理输出已关闭。
- MES 保留既有代码 0、1、200 的兼容含义，实际服务仍须按其接口契约验收。
- UDS 抑制正响应只能确认请求发送，不能据此证明 ECU 已执行。
- 本轮复查没有新的可确认问题不等于证明整个软件无 BUG。
