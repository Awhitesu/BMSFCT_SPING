# UDS列表编辑修复

原因：编辑工步界面创建了删除、上移、下移、清空、循环次数及请求间隔的工具栏，但没有把此布局加入UDS页面。已有删除函数因无界面入口而无法使用。

修复：将工具栏放在UDS表格上方；支持Ctrl/Shift多选整行后“删除选中行”，或右键删除、Delete键。Delete仅在表格自身有焦点时生效，单元格编辑中仍按文本编辑处理。按行号倒序删除，避免索引移动误删；没有选中行不删除。保留上移、下移、清空功能。

导入/重新打开的LIST64内容与手工创建行使用相同编辑方式。删除后仅从当前表格重新生成LIST64，保存、重新打开不会恢复被删内容，剩余解析规则和DLL解锁配置仍保留。修改工步后还需保存所属配方。

联合调试免扫码与MES前置回归：logs/debug_no_scan_uds_delete，20 passed。测试覆盖导入后多选删除、控件实际挂载到页面、保存回读、清空、正常生产继续要求扫码、调试不执行前置MES请求。
