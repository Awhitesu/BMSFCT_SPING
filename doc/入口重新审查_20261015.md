# 入口重新审查

从 main.py、登录、初始密码修改、账户管理、启动自检到主窗口构造重新检查。只修改源码，没有连接实际仪器、打包或推送。

本次确认并修复：

1. 主窗口构造阶段曾写死 ADMIN，界面创建后才替换成登录账户。现在从进程已验证会话读取用户名，避免初始化权限和账户显示使用错误身份。
2. 自检成功后排队的自动进入回调可能覆盖用户退出，或在重新自检后执行。现在检查自检轮次和退出状态；关闭窗口也会撤销自动进入。
3. 自检日志直接插入 HTML，设备错误中的尖括号内容可能消失。现在转义日志正文并保留原文。
4. 修改或删除已不存在的账户仍返回成功。现在检查数据库实际影响行数，保留失败结果。

新增 tests/test_entry_reaudit.py，覆盖退出和关闭与自动进入竞争、新旧自检轮次、正常自动进入、日志原文、账户消失以及主窗口初始账户。完整回归：650 passed，244 subtests passed，耗时 31.38 秒。

此轮未进行现场硬件联调；入口检查通过不代表其他模块无缺陷。
