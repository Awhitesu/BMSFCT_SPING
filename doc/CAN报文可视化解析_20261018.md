# CAN 报文解析

入口：编辑报文交互工步，选择“交互/问答”“读取数据”或“接收指定帧ID”，勾选“解析返回数据”。单纯发送指令不解析响应。旧工步默认关闭解析，保持原行为。

填写顺序：返回样例或期望长度 → 提取方式和位置 → 数据类型与字节序 → 系数、偏移、单位。Byte 从 0 开始。手动输入与 Byte/Bit 表高亮同步，点击或拖选表格可填写参数。样例仅辅助预览，不会作为实际返回数据保存运行。

按字节支持无符号整数、有符号整数、IEEE 754 的 4/8 字节浮点数、HEX、ASCII。按位支持有符号和无符号整数。位地址按 B0.bit0 到 B0.bit7、B1.bit0 递增，首个选定位为结果最低位；不是 DBC Motorola 位编号。跨字节位段可直接手填。

数值换算为 原始值 × 系数 + 偏移；文字和 HEX 禁止数值换算。实际报文长度必须与设置完全一致；长度不符、越界、无效类型和非有限数值均失败。解析结果作为工步结果，若需用于测试项上下限，应勾选工步“结果输出并参与判定”。单位用于配置说明和日志，上下限按换算后的单位设置，不会自动转换测试项单位。

预览与运行共用 core/can_data_parser.py。配置编码保存在工步参数 PARSE 中。运行日志记录完整返回数据、解析配置、原始值和最终值。普通 CAN/CAN FD 单帧最多 64 字节，本功能不把普通 CAN 自动升级为 UDS 或拼接多帧。

测试：tests/test_can_data_parser.py 覆盖解析、非法配置、手输与表格同步、保存回读和运行解析日志；联合物理通道路由测试在 logs/can_parser_final_targeted 中。离线模拟验证，没有向实际设备发送报文。
