# 板卡统一硬件管理

硬件管理中心加入全部14块板卡：绝缘2、电阻6、Relay1、HV1、HSD2、DMM2。每行显示启用、IP、TCP端口、Unit ID、状态、序号和固定通道数量。电阻板序号1–6可编辑，其他板卡序号只读。未启用设备可通过页面顶部“显示未启用设备”查看。

管理中心直接读写现有 rn_boards 配置，没有新增独立启用开关。初始化仅连接已启用板卡。禁用并保存后，下次初始化跳过该卡。保存并应用仍沿用原有后台任务、安全关闭旧输出、断开旧连接的流程；普通状态刷新读取缓存，不发送额外板卡请求。

连接参数与分类调试页同步；切回页面时刷新外部已保存的板卡配置，管理中心保留其他仪器未保存草稿。保存时检测外部修改，防止旧页面覆盖新配置。绝缘量程、电阻板序号及其他已有扩展配置字段会保留。量程选择和板卡输出控制仍在各自调试页。

启用板卡需填写有效IPv4；校验端口1–65535、Unit ID 0–255、已启用板卡IP/端口不重复、已启用电阻板序号不重复。连接失败信息出现在连接状态的提示中；有修改尚未应用时显示“修改未应用”或“停用未应用”。保存成功不代表实际连接成功。
