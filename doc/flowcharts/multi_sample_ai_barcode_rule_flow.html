🎯 工业级多样本 AI 条码规则对比推导算法流程图

多样本位置特征对比分析 (LCP / LCS / 动态字符集与长度范围提取)

graph TD
    Start["输入 N 个真实条码样本 (逗号/换行/空格分隔)"] --> ParseSamples["提取并清洗样本列表 (过滤空白项)"]
    ParseSamples --> CountCheck{"样本数量校验"}
    CountCheck -- "N = 1" --> SingleSample["采用单样本启发式规则推导 (给出多样本输入提示)"]
    CountCheck -- "N >= 2" --> MultiCompare["启动多样本对比引擎 (Multi-Sample Engine)"]
    
    MultiCompare --> ExtractLCP["1. 计算最长公共前缀 (LCP) -> 提取固定前缀 (如 SCUx03XP)"]
    ExtractLCP --> ExtractLCS["2. 计算最长公共后缀 (LCS) -> 提取固定后缀"]
    ExtractLCS --> AnalyzeMid["3. 截取中间变化号段，分析字符集 (纯数字 / 大写字母数字 / 混合字符)"]
    AnalyzeMid --> CalcLen["4. 计算号段长度或区间范围 ([min_len ~ max_len])"]
    
    SingleSample --> Synthesize["合成标准正则表达式 (例: ^SCUx03XP[A-Z0-9]{13}$)"]
    CalcLen --> Synthesize
    
    Synthesize --> AutoRegression["自动针对所有输入样本执行全量回归匹配打分"]
    AutoRegression --> ShowReport["填入配方规则输入框，输出 100% 打分回归报告弹窗"]
    ShowReport --> Finish["完成配方条码 AI 规则设定并持久化保存"]
