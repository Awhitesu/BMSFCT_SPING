    StartNode["发送 UDS 诊断请求并接收响应字节流(Raw Bytes)"]
    CheckPositive["校验肯定响应(SID+0x40)及前缀"]
    RespFail["否定响应 NRC 或超时: 判定失败"]
    CheckParserMode["判断用户配置的数据解析模式(Mode)"]
    ModeNone["无数据提取: 仅执行常规响应前缀校验"]
    ModeASCII["模式 A: 转换为 ASCII 文本(如 VIN/版本号)"]
    ModeCalc["模式 B: 拼接字节并进行数值公式计算"]
    
    SliceASCII["按偏移量截取数据字节(如跳过前3字节)"]
    DecodeASCII["执行 ASCII/UTF-8 解码并清洗非法字符"]
    SaveASCIIVar["写回全局变量(如 VIN_CODE)并用于字符串判定"]

    SliceBytes["按指定范围切片字节(如 Byte[3:5])"]
    ParseEndian["按大小端(Big/Little)合成整数(无符号/有符号)"]
    ApplyFormula["执行加减乘除计算(值 = 原始值 * 比例 + 偏移量 或 自定义公式)"]
    SaveNumVar["写回全局变量(如 PACK_VOLT)并用于上下限范围判定"]

    EndNode["工步执行完成, 输出最终数值/文本并在日志展示"]

    StartNode --> CheckPositive
    CheckPositive -->|失败| RespFail
    CheckPositive -->|成功| CheckParserMode
    CheckParserMode -->|无提取| ModeNone
    CheckParserMode -->|ASCII模式| ModeASCII
    CheckParserMode -->|数值计算模式| ModeCalc

    ModeASCII --> SliceASCII
    SliceASCII --> DecodeASCII
    DecodeASCII --> SaveASCIIVar
    SaveASCIIVar --> EndNode

    ModeCalc --> SliceBytes
    SliceBytes --> ParseEndian
    ParseEndian --> ApplyFormula
    ApplyFormula --> SaveNumVar
    SaveNumVar --> EndNode

    ModeNone --> EndNode

    class RespFail fail;
    class EndNode success;
