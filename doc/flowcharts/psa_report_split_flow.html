BMS 本地报表拆分与合成业务逻辑流程图

本图描述了测试结束后在本地生成报表的逻辑：首先保留原有的合并报表生成逻辑；随后根据测试配方文件中的 target_board 属性将测试结果拆分为主机、从机1、从机2、从机3四部分；最后根据 SN 条码与历史数据进行纵向汇总合并，自动完成 PASS/FAIL 命名转换和自锁，输出至 reports/PSA/{板卡}/ 目录下。

    Start["开始生成报表"]
    ReadDB["读取数据库 test_main 和 test_items_results"]
    OldReport["生成原有合并报表 (reports/yyyy-mm-dd/CHxx/ 不变)"]
    LoadRecipe["加载当前测试配方 JSON"]
    BuildMap["建立 测试项 -> 目标板卡 映射表"]
    GroupItems["按目标板卡对测试结果进行分组"]
    LoopBoards["遍历 主机, 从机1, 从机2, 从机3"]
    CheckActive["此板卡有测试项且条码存在?"]
    CheckExist["本地是否存在该 SN 的汇总报表?"]
    ReadHistory["提取首次开始时间并提取历史详细判定数据"]
    DecideResult["本次是否含 FAIL 或历史已含 FAIL?"]
    SaveFail["设定为 FAIL 状态并删除旧 PASS 报表"]
    SavePass["设定为 PASS 状态"]
    WriteCSV["写入/追加历史与本次数据到 reports/PSA/板卡/SN_状态.csv"]
    End["完成报表生成"]

    Start --> ReadDB
    ReadDB --> OldReport
    OldReport --> LoadRecipe
    LoadRecipe --> BuildMap
    BuildMap --> GroupItems
    GroupItems --> LoopBoards
    LoopBoards --> CheckActive
    CheckActive -- "是" --> CheckExist
    CheckActive -- "否" --> LoopBoards
    CheckExist -- "是" --> ReadHistory --> DecideResult
    CheckExist -- "否" --> DecideResult
    DecideResult -- "是" --> SaveFail --> WriteCSV
    DecideResult -- "否" --> SavePass --> WriteCSV
    WriteCSV --> LoopBoards
    LoopBoards -- "遍历结束" --> End

    class CheckExist condition;
    class DecideResult condition;
    class SavePass success;
    class SaveFail failed;
