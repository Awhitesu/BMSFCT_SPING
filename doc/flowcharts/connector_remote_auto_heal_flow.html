🚀 互联工具开发端远程智能自愈 (零人工干预)

当检测到机台未创建共享或返回系统错误 67 时，自动通过远程 SSH 通道静默配置并发布机台共享并自动挂载

graph TD
    Start["开发端点击【一键连接并保活】"] --> TryMount["尝试执行本地 net use 挂载 Z: 盘"]
    TryMount --> CheckMount{"挂载是否成功"}
    CheckMount -- "成功" --> StartKeepAlive["启动 25 秒心跳保活守护线程"]
    CheckMount -- "失败 (如错误 67 找不到网络名)" --> TriggerAutoHeal["触发软件内置【远程智能自愈模块】"]
    
    TriggerAutoHeal --> SSHConnect["利用配置的 IP/SSH端口/账密 建立远程 SSH 通道"]
    SSHConnect --> CheckRemoteShare{"远程检查机台是否存在 GX_APP 共享"}
    CheckRemoteShare -- "不存在" --> AutoLocate["远程检索机台工程目录 (如 D:\GX_APP刷写设备)"]
    AutoLocate --> RemoteCreate["远程执行 New-SmbShare 静默发布共享"]
    CheckRemoteShare -- "已存在" --> RetryMount["重新发起本地 net use 挂载"]
    RemoteCreate --> RetryMount
    
    RetryMount --> VerifySuccess{"二次挂载校验"}
    VerifySuccess -- "成功" --> StartKeepAlive
    VerifySuccess -- "异常" --> ReportDetail["输出精准诊断与修复日志"]
    StartKeepAlive --> Finish["终点: Z: 盘挂载成功并稳定心跳保活 (全程零人工干预)"]
