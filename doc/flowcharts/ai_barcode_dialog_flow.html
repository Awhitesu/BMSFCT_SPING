🎯 AiBarcodeRuleDialog 专属推导弹窗交互流程图

主界面极简保持，专有弹窗扫码推导 + 实时验证 + 一键填入配方规则

graph TD
    Start["配方编辑主页 (ConfigTab) 点击 🤖 AI 智能样本推导"] --> OpenModal["弹出专有对话框 AiBarcodeRuleDialog"]
    OpenModal --> FocusScan["扫码枪连续扫码 / 手动输入并添加样本条码"]
    FocusScan --> UpdateList["已扫样本列表视图 (samples_list_widget) 实时刷新"]
    UpdateList --> LiveEngine["触发 _recalculate_ai_rule() AI 对比分析引擎"]
    
    LiveEngine --> LCP["抽取最长公共前缀 (LCP) -> 识别固定前缀 (如 SCUx03XP)"]
    LCP --> LCS["抽取最长公共后缀 (LCS)"]
    LCS --> CharAnalysis["分析中间号段字符集及长度约束 -> 生成正则表达式"]
    CharAnalysis --> Render看板["看板实时渲染展示推导正则与特征拆解报告"]
    
    Render看板 --> OptionalTest["(可选) 在验证框扫入测试条码 -> 实时 🟢通过 / 🔴不符"]
    OptionalTest --> ClickConfirm["点击 ✅ 确认应用规则到配方"]
    ClickConfirm --> WriteBack["将 generated_regex 填回主界面 self.edit_master_sn_regex"]
    WriteBack --> Finish["关闭弹窗，完成配方条码规则设定"]
