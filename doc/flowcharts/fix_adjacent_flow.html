相邻电芯异常电压自动修正业务流程图

此图展示了在开启 FIX_ADJACENT 修正逻辑下，对相邻两单体电压之和为 4.5V~5.5V 的异常判定与修正流程。

    classDef start_end fill:#855CF8,stroke:#333,stroke-width:2px,color:#fff;
    classDef normal fill:#3B82F6,stroke:#333,stroke-width:2px,color:#fff;
    classDef condition fill:#F59E0B,stroke:#333,stroke-width:2px,color:#fff;
    classDef success fill:#10B981,stroke:#333,stroke-width:2px,color:#fff;
    classDef failed fill:#EF4444,stroke:#333,stroke-width:2px,color:#fff;

    Start["开始判定当前相邻单体对 (idx1, idx2)"]
    CheckNone["两单体读取值 val1, val2 是否均不为空?"]
    CalcBound["获取判定上下限 check_min, check_max"]
    CheckV1NG["单体1是否不在正常范围内? (val1 < check_min 或 val1 > check_max)"]
    CheckV2NG["单体2是否不在正常范围内? (val2 < check_min 或 val2 > check_max)"]
    CheckAnyNG["是否至少有一个单体不在正常范围内? (is_v1_ng 或 is_v2_ng)"]
    CalcSum["计算两单体电压之和 total_val = val1 + val2"]
    CheckSum["电压之和是否在 4.5V ~ 5.5V 之间?"]
    ApplyFix["执行修正: 将两单体电压均设为 2.499V"]
    KeepOrigin["保持原值: 不进行修正"]
    End["结束当前单体对判定"]

    Start --> CheckNone
    CheckNone -- "否" --> KeepOrigin
    CheckNone -- "是" --> CalcBound
    CalcBound --> CheckV1NG
    CheckV1NG --> CheckV2NG
    CheckV2NG --> CheckAnyNG
    CheckAnyNG -- "否" --> KeepOrigin
    CheckAnyNG -- "是" --> CalcSum
    CalcSum --> CheckSum
    CheckSum -- "是" --> ApplyFix
    CheckSum -- "否" --> KeepOrigin
    ApplyFix --> End
    KeepOrigin --> End

    class Start start_end;
    class End start_end;
    class CalcBound normal;
    class CheckV1NG normal;
    class CheckV2NG normal;
    class CalcSum normal;
    class CheckNone condition;
    class CheckAnyNG condition;
    class CheckSum condition;
    class ApplyFix success;
    class KeepOrigin failed;
