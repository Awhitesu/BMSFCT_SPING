# 设备调试响应性检查

检查日期：2026-10-13。只修改源码，未打包。

## 检查与处理

| 设备 | 调试页处理 |
|---|---|
| 电池模拟器（最多6台） | 单通道设压、输出、回读、量程、限流和配置应用均在后台执行；批量操作按设备并行、设备内顺序执行；保留回读确认。 |
| NGI 高压源 | 连接、断开、设压、设流、输出及测量使用同一后台执行器，不重复叠加任务。 |
| IT6722A | 连接、断开、设置、输出及测量串行后台执行，避免多个按钮覆盖未结束的任务。 |
| IT6333B | 已采用后台任务及重复执行保护，检查并验证界面响应。 |
| 34461A | 测量和连接使用后台任务；隐藏调试页暂停连续测量。 |
| DG2052、TBS2102B | 连接、设置、测量及波形读取已使用后台任务；检查并验证界面响应。 |
| EASY320 | 后台串行通信，复用工作线程；隐藏页暂停调试回读。自动化序列的PLC信号监听继续工作。 |
| CA550 | 复用串口工作线程；队列最多32个待执行命令；轮询不在忙碌时加入任务；串口读写均设超时；异常后线程继续工作。 |
| 绝缘、电阻、继电器、HV、HSD、DMM板卡 | 后台通信及配置应用；复用工作线程；仅显示的控制页进行继电器自动回读；相同状态不重复重绘；切换板卡后忽略旧板卡回读结果。 |
| PCAN / ZLG CAN | 连接、断开、发送和四通道设置均在后台；UDS防重复执行；隐藏页不刷新报文表，后台接收及协议分发继续工作。 |
| SG400、瑞萨E2 | 下载操作原已在后台执行；工程预览增加300ms输入等待和单任务保护；旧工程预览结果不覆盖新选择。 |
| 硬件管理中心 | 接口扫描在后台；加载配置使用缓存的接口列表；更新表格时阻断重复变更信号。 |

降低常态下Modbus逐帧日志输出量。需要诊断逐帧日志时，可设置环境变量 `GX_VERBOSE_IO=1` 后启动。

## 验证

共71项相关测试通过：慢通信界面响应、工作线程复用、重复任务保护、异常恢复、接口扫描、CA550队列上限、板卡隐藏页及差量刷新，以及模拟器、万用表、信号发生器、电源、示波器、板卡、UDS、E2的功能回归。

模拟慢通信时检查界面定时器仍持续响应，设备动作在工作线程执行；没有操作现场仪器输出。界面操作不等待仪器响应，实际通信耗时仍取决于设备、网络和既定校验步骤。

重启 `main.py` 后新代码才生效。现场建议依次连接设备，切换调试页，并在设备断网时检查窗口拖动、导航和滚动是否正常；自动化测试中再确认CAN、PLC监听及测试结果。
