# 泰克 TBS2102B 网口调试

TBS2102B 是 Tektronix（泰克）双通道示波器。使用 LAN/VXI-11 资源 `TCPIP0::设备IP::inst0::INSTR`，不使用信号发生器的5555端口。依赖 PyVISA 和 PyVISA-py，已加入 requirements.txt。

## 推荐操作

1. 连接仪表，确认型号。匹配实际探头倍率，例如10×。
2. 设置通道耦合、V/div和时基，使波形占据适当屏幕范围。
3. 设置触发来源、类型、电平，应用触发设置。
4. 周期信号用连续运行；偶发事件用Normal模式加单次捕获，先启动捕获，再产生真实事件。
5. 查询触发状态。完成采集或停止后读取波形，可导出时间/电压CSV。

## 触发

- 边沿：选上升/下降沿及电平。3.3V逻辑信号可从1.65V开始调整。
- 脉宽：选正/负脉冲、小于/大于/等于/不等于条件及持续时间，适合找短毛刺或异常长脉冲。
- 欠幅：设置上下阈值，找幅度不足的脉冲；OCCURS捕获任意持续时间的欠幅事件。
- Auto：没有满足条件的事件也可能刷新，适合找信号。
- Normal：只有满足触发条件才刷新，等待不代表故障。
- 释抑：一次触发后暂时忽略事件，可用于稳定脉冲串。
- 高频/低频/噪声抑制只影响触发路径，不等同于通道耦合。
- 强制触发只在仪表准备好时有效。自动50%电平需要输入有效信号。

预设只填入表单，不会自动发送指令；应按实际电平调整后应用。波形是当前已采集记录，不是实时连续数据流。输入为接地参考，浮地或高压节点使用合适的差分探头。

## 参考与实现范围

- [官方 TBS2000B 编程手册](https://download.tek.com/manual/TBS2000B-Programmer-Manual-EN-US-077114904.pdf)：本型号指令、探头增益、触发及波形标定。
- [泰克官方 GitHub 示例仓库](https://github.com/tektronix/Programmatic-Control-Examples)。阅读了 `Examples/Oscilloscopes/BenchScopes/src/SimplePlotExample/tbs_simple_plot.py`；该示例面向旧款TBS/TDS，并非本型号完整驱动。参考其停止/单次采集流程及标定公式，代码按当前手册独立实现，未直接复制。
- 当前覆盖三种触发类型、通道、时基、采集、即时测量、波形及CSV。仪表拒绝设置会报告错误，部分此前发送的参数可能已经生效。实机兼容性尚待验证。
