# 独立变量工步

入口：通用交互 → 写入变量 / 读取变量。原“变量操作”入口保留以兼容旧配方。

示例：UDS三字段写入 → 写入变量（键名：追溯码，来源：上一个工步输出）→ UDS读取并解析ASCII → 测试项判定选择“变量”，期望键名选择“追溯码”。三字段工步输出实际写入的ASCII字符串，不含2E和DID；收到有效肯定响应后才输出。

每个子工步结果记录在本次执行中。写入变量可选上一个工步，也可按来源工步的稳定ID选择指定输出。失败、缺失或没有结果的来源禁止写入，并移除同名旧键，避免复用错误数据。新测试开始清空变量和工步输出。

读取变量自动列出当前配方中已配置的写入键名，允许手输键名兼容其他已有变量来源。没有分段时保持原始类型和值；添加分段后输出拼接字符串。变量未在本次执行中产生则失败，不以空字符串代替。

分段表包含起始位置、截取长度和输出格式；起始从1计数，长度0为到末尾。支持字符串截取、HEX字节解析为ASCII、HEX、BCD、大/小端无符号整数。可设置拼接分隔符，输入调试样本实时预览。调试样本不保存到配方，不作为生产值使用。截取越界、无效HEX、非法BCD均报错。

变量类型判定精确比较运行时变量值与测试输出；保留前导零，不自动忽略空格。键名下拉列出配方已定义的写入变量，不能把下拉出现当作运行时已经赋值。
