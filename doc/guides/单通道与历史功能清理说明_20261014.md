# 单通道与历史功能清理

已删除外部大屏 API 客户端和调试页，以及引擎的启动、进度、完成、完整结果上传、通道重置和温度心跳代码。原配置中的 api_host、api_port 已移除，MES 和 PLC 接口保留。

已删除多通道同步组、同步等待计时器、屏障看门狗、跨通道执行队列和批量启动逻辑。引擎同一时间只接受一个测试运行；停止收尾期间也不能通过其他通道号启动新运行。

旧配方同步字段和控制工步通过单通道适配器兼容；保留少量类型识别用于兼容，不再进入同步执行流程。

已删除历史老化板控制分支、老化板编辑参数页、额外设备页中的老化板操作、老化计数读写方法及首页累计次数控件。生产总数、合格数、不合格数和合格率仍保留。

老化板工步若仍存在于配方中会明确失败并提示更新，避免误报成功。环境温度不再从老化箱读取或默认为 25℃；温差计算需要已有的“环境温度”变量。

现有测试数据库和历史结果未删除；旧数据库内的历史计数字段也不进行破坏性删除。

设备驱动的通信锁、共享板卡实例、超时、取消与异步停止收尾仍保留。此次验证属于软件回归，没有操作现场仪器，也没有打包。
