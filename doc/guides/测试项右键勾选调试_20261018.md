# 测试项右键勾选调试

测试界面不增加按钮。测试项序号旁提供复选框，右击树中的测试项或其子工步可打开菜单：

- 调试当前测试项：运行右击位置所属的完整测试项。
- 调试勾选测试项：按原配方顺序运行勾选的一个或多个完整测试项。

未勾选项只在本次运行快照中标记跳过，不改原配方、不改变原有停用项状态。使用完整原顺序索引交给引擎，结果回填保持原行对应；跳过的父项及子工步显示灰色SKIP。

正常“开始”仍运行整个配方，不受调试勾选影响。右键调试仅管理员可用，运行或准备中不可启动新的调试。加载配方重新清空勾选。

调试不要求扫码，不校验生产条码规则，并跳过MES前置过站检查；SN输入框已有内容可作为调试上下文，空白也能运行。正常生产开始仍必须扫码并执行已启用的MES检查。配方硬件准备及设备连接检查保持执行。不自动插入未勾选的初始化、供电或变量准备步骤，调试人员需要选齐依赖。

调试运行显示DEBUG；结束显示DEBUG PASS/DEBUG FAIL，界面日志注明调试用途。引擎使用正式的`debug_run`标记和`test_id=-1`禁止创建生产记录。仍复用共享设备实例、互斥、停止与输出清理；不绕过设备控制。调试不计入良率、产品数量和连续不良报警。原有设备烧录留痕及实际MES工步等副作用仍按所选工步执行，不伪称全部无外部影响。

测试覆盖：勾选快照与原配方隔离、调试跳过MES前置检查、调试不创建生产记录、结果不改变统计及报警、实际引擎无生产记录运行。相关文件为`tests/test_selected_item_debug.py`和`tests/test_debug_no_scan_and_uds_delete.py`。
