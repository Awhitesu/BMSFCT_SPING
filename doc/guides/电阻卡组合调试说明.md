# 电阻卡组合调试

电阻板调试页将6块、每块6通道组合为一套CH1–CH36设备。在连接配置页为每块卡设置排序序号1–6，启用的卡不能使用重复序号。

| 排序序号 | 全局通道 | 本板通道 |
|---|---|---|
| 1 | CH1–CH6 | CH1–CH6 |
| 2 | CH7–CH12 | CH1–CH6 |
| 3 | CH13–CH18 | CH1–CH6 |
| 4 | CH19–CH24 | CH1–CH6 |
| 5 | CH25–CH30 | CH1–CH6 |
| 6 | CH31–CH36 | CH1–CH6 |

每个通道可以独立设置阻值和回读。上方批量阻值可以应用到勾选通道或全部已启用通道。全选只勾选有效通道，未启用卡对应的通道保持原编号并禁用，不压缩编号。

修改序号、IP、端口等参数后点击保存并应用。该操作断开旧连接，更新映射，不写阻值。后续设置或回读会自动连接对应卡。

不同卡并行执行，同卡通道顺序执行。成功回读值和失败原因显示在各个通道，顶部给出耗时及失败通道，不把部分成功当作全部成功。

阻值范围0–1,500,000Ω、10Ω步进。0Ω是有效电阻设定，不表示绝缘板的关闭命令。回读值为板卡保存的设定值；实测电阻需要万用表测量。

本次组合操作在电阻卡调试页实现，其他板卡调试保持按种类及板号独立控制。已有电阻板测试步仍按原配置槽位和本板通道寻址，未改变旧配方含义。
