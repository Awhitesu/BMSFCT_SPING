# UDS读取只输出提取结果

修复前：UDS列表只有一个提取值时输出解析值；多行或多轮提取时却返回原始HEX和解析结果拼接的字符串，导致VIN等字符串判定不便。

修复后：凡配置数据提取，只把提取值用于工步结果，不拼接原始报文或切会话、DLL解锁等控制响应。只有一个提取行时输出该行最终值；多行用竖线分隔提取值；循环执行时保留每行最后一轮结果，不重复拼接历次VIN。原始TX/RX及逐次提取过程仍完整写日志。没有提取配置的旧工步仍返回原始HEX。显式填写了无效提取规则则失败，不再静默回退HEX。

读取类服务19/22/23/24默认不填写额外期望响应，协议层仍执行UDS肯定响应、SID和适用的回显字段检查。需要额外校验时可以手工填写；已有配方显式保存的期望值继续生效，不自动删除。

读取VIN配置：请求22 F1 90，额外期望响应留空，ASCII提取偏移3、长度17（按实际ECU协议调整）。测试值只显示VIN，如LFVBA21A1N0000001。选中“结果输出并参与判定”即可用于测试项字符串判定。VIN标准内容在测试项层配置，不应写成整条响应HEX。

读取服务的在线抓取结果用于字节表预览，不会自动写成固定期望报文。切换请求时清除旧预览，避免使用旧样例。

回归日志 logs/uds_extracted_output_final 覆盖单次/循环VIN、多行提取、控制响应不混入、原始报文保留日志、非法规则失败和UI默认值，并联合原UDS引擎、解析器、模板、列表删除及DLL安全访问测试。没有发送真实CAN报文。
