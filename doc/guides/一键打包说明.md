# 一键打包

从项目根目录运行下面的 `tools/package_app.py` 命令。当前工作区的“打包应用程序.bat”已在本次整理前删除。使用依赖完整的项目 Python 环境；默认目录版：dist/BMSFCT/BMS软件注入&APP刷写系统.exe，交付时复制整个 BMSFCT 文件夹。构建配置现位于 `packaging/AgingTest_BMS.spec`。

后续保留 build 目录，自动复用 PyInstaller 缓存。目录版避免单文件每次压装和运行时解压，通常更适合日常更新。第一次构建仍需完整扫描依赖。

命令行可选：

```powershell
.venv\Scripts\python.exe tools/package_app.py --check
.venv\Scripts\python.exe tools/package_app.py
.venv\Scripts\python.exe tools/package_app.py --onefile
.venv\Scripts\python.exe tools/package_app.py --clean
```

--check 只检查环境；--onefile 生成 dist/BMSFCT-onefile 下的单文件版；--clean 仅重建打包缓存，不清空运行配置；--open 完成后打开目录。单文件版同样需要旁边的 config 和 recipes 目录保存可写配置。

构建在 build/<模式>/staging 内完成，成功后才复制应用文件到成品目录。现有成品目录中的 config、recipes、数据库和日志不删除。首次生成时复制项目配置及配方；以后只补充不存在的文件，不覆盖机台已有配置和配方。若要更新同名配方，应在软件中导入或自行替换。成品不存在数据库时，通过 SQLite 在线备份复制项目 bms_test_data.db，包含人员账号、密码存储值、权限、系统参数和已有测试记录；已有成品数据库始终保留，不覆盖机台账号或历史记录。

打包前请关闭成品 EXE；不要同时运行多个打包进程。更新目录可能需要重新复制全部文件，不能只复制 EXE。设备内核驱动、VISA 和瑞萨 RFP 等厂商安装环境仍需在目标电脑安装，配置中的绝对文件路径需按目标机调整。ZLG SDK、PCAN DLL、力捷丰 DLL 和界面资源已列入构建。

日志：logs/packaging。成品 build-info.json 记录构建时间、依赖版本、耗时和 EXE SHA256。脚本不会自动连接仪器或开启输出。
