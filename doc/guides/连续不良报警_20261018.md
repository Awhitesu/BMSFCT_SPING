# 连续不良报警

入口：软件设置 → 连续不良报警。勾选启用、填写连续N片（1–10000，默认3）并保存。启用状态与阈值持久化，默认关闭。

计数规则：

- 仅对本工位已完成且无记录错误的测试结果计数。
- 连续NG累计到N片时弹出“连续不良报警”，显示当前连续数、阈值及条码。
- 同一连续区段内，同一条码反复NG只计一片，重复完成信号通过执行ID去重。
- 出现一次正常完成的OK即清零，重新开始累计。
- 每段连续不良仅弹窗一次，后续NG不逐片重复弹窗；出现OK后恢复下一轮报警。
- 手动停止、取消、MES前置拦截及记录错误不作为不良片数，不改变当前连续区段。
- 保存报警设置、关闭启用或重启软件后重新计数；不从历史良率统计反推连续数。

弹窗采用非阻塞Qt打开方式，使测试引擎的完成回调和线程清理可以继续。弹窗未确认前阻止新测试启动；确认只是关闭提示，不清空当前不良连续区段，不自动操作设备。

不改变现有条码去重良率统计口径。配置键为`ng_alarm_enabled`和`ng_alarm_threshold`，测试或准备中不允许修改。

测试覆盖：阈值、OK清零、同条码复测、重复信号、关闭与重新配置、错误阈值、设置保存信号、其他通道/取消/记录异常排除，以及弹窗不阻塞完成处理。

回归入口：`tests/test_consecutive_ng_alarm.py`；定向日志：`logs/consecutive_ng_targeted_20261018`；完整回归日志：`logs/consecutive_ng_full_20261018`。
