# EASY320 调试页通道导入

进入硬件独立调试的 EASY320 页面，点击“导入通道Excel”。文件使用 `.xlsx` 或 `.xlsm`，第一行包括“序号”和“名称”，读取当前活动工作表。

| 序号 | 名称 |
|---|---|
| DO0 | 平推气缸 |
| DO1 | 上升气缸 |
| DO2 | 下降气缸 |
| DO7 | |
| DO10 | |

DO后面的数字是八进制，顺序为 DO0–DO7、DO10–DO17、DO20–DO27……。DO10对应零起始通道偏移8，DO17对应15；不会把Excel行号当作硬件地址。

有效编号有多少行，页面就显示多少个按钮；名称可以为空。全空行忽略，编号缺失、非八进制编号及重复地址会拒绝整份导入并保留原配置。按钮按地址顺序排列，可以只导入部分或不连续的通道。

导入不会直接写输出。之后单个按钮只控制对应DO；“全部开启/关闭”和周期回读只操作导入的通道，不操作未导入地址。配置保存在系统配置文件，软件重启后自动加载。

继电器DO的Modbus基址统一为 `0xFC00`，DO编号按八进制转换为零起始偏移后相加。独立调试、自动测试、单点和批量读写共用此基址：`DO0 → 0xFC00`、`DO7 → 0xFC07`、`DO10 → 0xFC08`、`DO20 → 0xFC10`。Excel中的DO编号和名称保持原样。

附带模板为16路示例，可增删行。测试覆盖了40路导入和300路分段读取，不以这些数量限制界面；硬件实际支持的DO地址范围由所连接设备决定。
