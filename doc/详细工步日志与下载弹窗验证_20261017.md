# 详细工步日志与下载弹窗

## 工步日志

执行引擎每次进入子工步逻辑时，输出完整结构化配置参数、设备、动作、工步 ID、失败策略、父测试项名称、上下限、单位及判定方式。重试保留本次重试编号。通过 TestEngine.log_message 转发到主界面底部日志，因此驱动过程信息、异常与重试提示也会显示。

原有子工步结果继续显示；即使树形列表中暂时没有对应行，结果日志也不再被布局条件丢弃。日志参数来自执行引擎实际使用的配置，不是从表格显示文字反推；不将这些配置参数冒充仪器实测值。结构化密码、令牌等字段沿用凭据过滤逻辑。此处完善的是本轮界面日志和现有 worker 日志历史，未新增独立的永久日志文件或数据库列。

## 下载弹窗

- 保留用户改成非模态弹窗的方式，APP、SG400、E2 活动状态自动打开监控；界面仍可操作停止按钮。
- 手动关闭后，本轮不反复弹出；新一轮测试复位后允许再次打开。结束保留最终状态。
- 终态去重改为 started_at、kind、project、result 组合，同一轮两个项目均 PASS 也分别记录，同一任务重复状态不重复记。
- 窗口拉宽时重新计算文字省略。刷新由弹窗自己的单次 QTimer 管理，隐藏停止；不保留销毁后仍可执行的无上下文延迟刷新。
- 退出时停止 SG/E2 显示计时器、隐藏监控窗口；关闭过程不再接受迟到的状态信号重新弹窗。
