# RN-EOL 绝缘电阻卡 - Modbus TCP接口文档

## 概述

RN-EOL绝缘电阻卡基于STM32F407VET6，通过继电器阵列输出可编程的绝缘电阻，并通过Modbus TCP提供远程控制接口。

固件有两种型号，寄存器映射和协议完全相同，只有阻值范围不同：

| 型号 | 构建环境 | 阻值范围 | 分辨率 |
|------|----------|----------|--------|
| 5MΩ  | `Resistor_Card` | 0Ω - 5,000,000Ω | 1kΩ |
| 30MΩ | `Resistor_Card_30M` | 0Ω - 30,000,000Ω | 1kΩ |

两种型号的设备ID和固件版本寄存器相同，上位机无法通过寄存器区分型号。请按板卡标签确认型号，或写入超出5MΩ的阻值，看是否返回异常码 0x03。

## 系统特性

### 硬件特性
- **控制方式**: 18路阻值继电器 + 1路输出隔离继电器K19 (ULN2803A驱动)
- **分辨率**: 1kΩ
- **网络接口**: 以太网 (KSZ8863RLLI, RMII接口)
- **通信协议**: Modbus TCP (端口502)

### 协议特性
- **协议栈**: LwIP TCP/IP
- **最大客户端**: 1个连接，新连接会关闭旧连接
- **支持功能码**: 0x03, 0x04, 0x06, 0x10
- **寄存器空间**: 0x0000-0x011F，共288个16位寄存器
- **单元标识符 (Unit ID)**: 不校验，任意值均可，响应原样返回
- **字节序**: 大端（Modbus标准）；32位阻值高16位在前

## Modbus寄存器映射

### 电阻控制寄存器 (0x0000-0x000F)

保留8通道寄存器结构以兼容旧上位机，实际只有CH1有效：

| 地址 | 描述 | 访问 | 状态 |
|------|------|------|------|
| 0x0000 | CH1电阻值高16位 | 读写 | ✅ 有效 |
| 0x0001 | CH1电阻值低16位 | 读写 | ✅ 有效 |
| 0x0002-0x000F | CH2-CH8 | - | ⚠️ 兼容保留，不要写入 |

**电阻值计算**: `resistance = (high_reg << 16) | low_reg`，单位Ω

**写入规则**:
- 阻值必须在型号范围内，且是1000的整数倍，否则返回异常码 0x03，阻值不变
- 写入0Ω：关闭全部阻值继电器，K19吸合，输出端断开
- 写入非0阻值：按贪心算法接入继电器，K19释放，输出设定阻值
- 上电默认为0Ω（输出断开）

**推荐用 0x10 一次写入 0x0000-0x0001。** 用 0x06 分两次写时，每次写入都会和另一半的当前值拼成32位阻值，立即校验并输出。例如从123000Ω (0x0001_E078) 改为 65000Ω (0x0000_FDE8)，先写高16位得到 0x0000_E078 = 57464Ω，不是1000的整数倍，会被拒绝。

### 系统信息寄存器 (0x0100-0x0104)

| 地址 | 描述 | 值 | 说明 |
|------|------|-----|------|
| 0x0100 | 系统状态 | 0x0001 | 0x0001=就绪，0x0000=电阻控制未初始化 |
| 0x0101 | 设备ID | 0x5254 | ASCII "RT" |
| 0x0102 | 固件版本 | 0x0102 | 高字节主版本，低字节次版本：v1.2 |
| 0x0103 | 通道使能 | 0x0001 | 见下文 |
| 0x0104 | 输出状态 | 0/1 | bit0=1 表示CH1当前有非0阻值输出 |

0x0100 和 0x0104 由固件持续刷新。0x0101、0x0102 是只读值，但固件不会拦截对它们的写入，写入后会一直保持被改动的值直到重启，请不要写这两个寄存器。

**0x0103 通道使能**（兼容旧上位机）:
- 上电读出为 0x0001
- 用 0x06 写入 bit0=0：关闭输出（效果等同写入0Ω），寄存器保存为0
- 用 0x06 写入 bit0=1：只保存数值，不会恢复输出；需要重新写入非0阻值
- 用 0x10 写入：只保存数值，不会关闭输出

新上位机建议直接写0Ω来关闭输出，用 0x0104 判断输出状态。

### 网络配置寄存器 (0x0110-0x0116)

| 地址 | 描述 | 格式 |
|------|------|------|
| 0x0110 | IP地址高16位 | IP[0]<<8 \| IP[1] |
| 0x0111 | IP地址低16位 | IP[2]<<8 \| IP[3] |
| 0x0112 | 子网掩码高16位 | 同上 |
| 0x0113 | 子网掩码低16位 | 同上 |
| 0x0114 | 网关地址高16位 | 同上 |
| 0x0115 | 网关地址低16位 | 同上 |
| 0x0116 | 网络控制 | 按位操作，见下表 |

启动时 0x0110-0x0115 显示当前生效的配置。写入这些寄存器只是暂存，不影响当前网络，需要通过 0x0116 保存，再重启后才生效。

**网络控制寄存器位定义 (0x0116)**:

| 位 | 名称 | 访问 | 说明 |
|----|------|------|------|
| bit0 | APPLY_CONFIG | 写1触发 | 校验 0x0110-0x0115 中的配置并保存到Flash |
| bit1 | RESTORE_DEFAULTS | 写1触发 | 恢复默认配置 (192.168.1.10) 并保存到Flash |
| bit8 | REBOOT_REQUIRED | 只读 | 保存成功后置1，表示需要重启生效 |
| bit12 | SOFTWARE_RESET | 写1触发 | 发送响应后软件重启 |

触发位执行后自动清零，bit8 保持到重启。

配置校验规则：IP不能是 0.0.0.0 或 255.255.255.255，子网掩码必须是连续的1。**校验失败时不会返回异常码**，写入仍然返回成功，但bit8不会置1，0x0110-0x0115 中的暂存值也不会被恢复。保存后请读回 0x0116 确认bit8为1。

### 系统控制寄存器 (0x011F)

| 地址 | 描述 | 说明 |
|------|------|------|
| 0x011F | 软件重启 | 写入 0x0001 触发重启，其他值无效果 |

设备先发送Modbus响应，再执行重启。重启后TCP连接断开，需要重新连接。

### 其他地址

0x0010-0x00FF、0x0105-0x010F、0x0117-0x011E 未定义，读出为0。写入不会报错，也没有任何功能。地址超过 0x011F 返回异常码 0x02。

## 继电器电阻组合

两种型号都用同一个贪心算法：
1. K1-K18按阻值从大到小排序
2. 继电器阻值 ≤ 剩余目标阻值时接入，并从剩余值中扣除
3. 遍历完全部继电器后结束

K19是输出隔离继电器（常闭点），不参与阻值计算。

### 5MΩ型号

| 档位 | 继电器 | 最大组合 |
|------|--------|----------|
| 1kΩ   | K1(1k) + K2-K5(2k×4) | 9kΩ |
| 10kΩ  | K6(10k) + K7-K10(20k×4) | 90kΩ |
| 100kΩ | K11(100k) + K12-K15(200k×4) | 900kΩ |
| 1MΩ   | K16(1M) + K17-K18(2M×2) | 5MΩ |

理论组合总阻值 5.999MΩ，软件限幅到5MΩ。

### 30MΩ型号

| 档位 | 继电器 | 最大组合 |
|------|--------|----------|
| 1kΩ   | K1(1k) + K2-K3(2k×2) + K4(5k) | 10kΩ |
| 10kΩ  | K5(10k) + K6-K7(20k×2) + K8(50k) | 100kΩ |
| 100kΩ | K9(100k) + K10-K11(200k×2) + K12(500k) | 1MΩ |
| 1MΩ   | K13(1M) + K14-K15(2M×2) + K16(5M) | 10MΩ |
| 10MΩ  | K17(10M) + K18(20M) | 30MΩ |

理论组合总阻值 41.11MΩ，软件限幅到30MΩ。

## 支持的Modbus功能码

### 0x03 / 0x04 - 读取保持寄存器 / 输入寄存器
两者行为相同，读取同一块寄存器空间。单次最多125个寄存器，数量为0、超过125或超出地址范围返回异常码 0x02。

**请求格式**:
```
功能码: 0x03 或 0x04
起始地址: 2字节
数量: 2字节
```

**示例 - 读取CH1电阻值**:
```
请求: 地址 0x0000, 数量 2
响应: [高16位] [低16位]
计算: resistance = (响应[0] << 16) | 响应[1]
```

### 0x06 - 写入单个寄存器

**请求格式**:
```
功能码: 0x06
寄存器地址: 2字节
寄存器值: 2字节
```

适合写网络控制 (0x0116) 和软件重启 (0x011F)。写阻值请用 0x10（原因见“写入规则”）。

### 0x10 - 写入多个寄存器
单次最多123个寄存器，数量为0、超过123、字节数不等于数量×2或超出地址范围返回异常码 0x02。

**请求格式**:
```
功能码: 0x10
起始地址: 2字节
数量: 2字节
字节数: 1字节
数据: N字节
```

**示例 - 设置CH1电阻值为123000Ω**:
```
target     = 123000 = 0x0001E078
high_value = 0x0001
low_value  = 0xE078

请求: 地址 0x0000, 数量 2, 字节数 4, 数据 [0x0001, 0xE078]
```

0x10 先校验阻值，校验失败时整个请求都不写入。

## 使用示例

### Python客户端示例 (pymodbus 3.x)

```python
from pymodbus.client import ModbusTcpClient
import time

client = ModbusTcpClient('192.168.1.10', port=502)
if not client.connect():
    print("连接失败")
    exit(1)

# 读取系统信息 0x0100-0x0104
info = client.read_holding_registers(0x0100, count=5)
if not info.isError():
    status, dev_id, fw, ch_en, output = info.registers
    print(f"系统状态: 0x{status:04X}")
    print(f"设备ID: {chr(dev_id >> 8)}{chr(dev_id & 0xFF)}")
    print(f"固件版本: v{fw >> 8}.{fw & 0xFF}")
    print(f"输出状态: {'输出中' if output & 1 else '已断开'}")

def set_resistance(ohms):
    return client.write_registers(0x0000, [(ohms >> 16) & 0xFFFF, ohms & 0xFFFF])

def get_resistance():
    rr = client.read_holding_registers(0x0000, count=2)
    return (rr.registers[0] << 16) | rr.registers[1]

# 5MΩ型号测试值；30MΩ型号可追加 10000000, 30000000
for target in [1000, 10000, 123000, 1000000, 5000000]:
    result = set_resistance(target)
    if result.isError():
        print(f"❌ 设置 {target:,} Ω 失败: {result}")
        continue
    time.sleep(0.1)  # 等待继电器稳定
    actual = get_resistance()
    print(f"目标: {target:,} Ω, 实际: {actual:,} Ω")

# 关闭输出
set_resistance(0)
client.close()
```

### 动态网络配置示例

```python
# 修改为 IP 192.168.1.100 / 掩码 255.255.255.0 / 网关 192.168.1.1
client.write_registers(0x0110, [0xC0A8, 0x0164,   # 192.168 / 1.100
                                0xFFFF, 0xFF00,   # 255.255 / 255.0
                                0xC0A8, 0x0101])  # 192.168 / 1.1

# 保存到Flash (bit0)
client.write_register(0x0116, 0x0001)

# 确认保存成功 (bit8)
ctrl = client.read_holding_registers(0x0116, count=1).registers[0]
if ctrl & 0x0100:
    print("✅ 配置已保存，重启后生效")
    client.write_register(0x011F, 0x0001)  # 软件重启
else:
    print("❌ 配置无效，未保存")
```

恢复默认网络配置：

```python
client.write_register(0x0116, 0x0002)  # RESTORE_DEFAULTS
client.write_register(0x011F, 0x0001)  # 重启后使用 192.168.1.10
```

### C# 客户端示例 (EasyModbus)

```csharp
using EasyModbus;

ModbusClient client = new ModbusClient("192.168.1.10", 502);
client.Connect();

// 读取当前电阻值
int[] values = client.ReadHoldingRegisters(0x0000, 2);
uint resistance = ((uint)values[0] << 16) | (uint)values[1];
Console.WriteLine($"当前电阻值: {resistance:N0} Ω");

// 设置电阻值为2,345,000Ω（0x10一次写入）
uint target = 2345000;
client.WriteMultipleRegisters(0x0000, new int[] {
    (int)(target >> 16),
    (int)(target & 0xFFFF)
});

// 读取系统信息 0x0100-0x0104
int[] info = client.ReadHoldingRegisters(0x0100, 5);
Console.WriteLine($"设备ID: {(char)(info[1] >> 8)}{(char)(info[1] & 0xFF)}");
Console.WriteLine($"固件版本: v{info[2] >> 8}.{info[2] & 0xFF}");
Console.WriteLine($"输出状态: {((info[4] & 1) != 0 ? "输出中" : "已断开")}");

client.Disconnect();
```

## 错误处理

| 异常码 | 说明 | 触发条件 |
|-------|------|----------|
| 0x01 | 非法功能码 | 功能码不是 0x03/0x04/0x06/0x10 |
| 0x02 | 非法数据地址 | 地址超过 0x011F；读取数量为0或超过125；写入数量为0或超过123；字节数不匹配 |
| 0x03 | 非法数据值 | 阻值超出型号范围或不是1000的整数倍；请求PDU长度不足 |
| 0x04 | 从设备故障 | 继电器设置失败；0x06写入CH2-CH8；0x0103写0时关闭输出失败 |

网络配置保存失败**不会**返回异常码，见 0x0116 说明。

## 故障排除

### 连接问题
1. **网络连接**: 确认电脑与设备在同一网段，ping 设备IP
2. **防火墙**: 允许502端口通信
3. **PHY状态**: 检查以太网链路LED
4. **连接被断开**: 只支持1个客户端，另一个程序连接后本连接会被关闭

### 通信错误
1. **寄存器地址**: 有效范围 0x0000-0x011F
2. **阻值被拒绝 (0x03)**: 检查是否超出型号范围，是否是1000的整数倍，是否用0x06分两次写入
3. **功能码**: 只支持 0x03, 0x04, 0x06, 0x10
4. **字节序**: 大端，32位阻值高16位在前

### 网络配置不生效
1. 保存后读 0x0116，bit8 为1才表示保存成功
2. 保存后必须重启（写 0x011F 或断电）
3. 检查子网掩码是否为连续的1，IP是否为 0.0.0.0 / 255.255.255.255
4. 忘记IP时，可通过串口日志 (115200) 查看启动时打印的当前IP

### 硬件问题
1. **继电器不动作**: 检查ULN2803A驱动和继电器线圈供电
2. **有阻值但无输出**: 读 0x0104 确认输出状态，检查K19(PC12)
3. **串口调试**: 查看115200波特率的详细日志

## 开发说明

### 修改阻值配置
继电器阻值表、贪心排序和最大阻值都在 `RELAY_RESISTANCE_PROFILE_30M` 宏下分两套：
1. `src/relay_control.c` 中的 `relay_resistance_values[]`（阻值表）

4. `include/relay_control.h` 中的 `MAX_RESISTANCE_OHMS`

## 常见问题

**Q: 为什么实际电阻值与目标值有误差？**
A: 寄存器读回的是设定值。实际输出阻值的误差来自电阻本身的公差和继电器接触电阻，固件无法测量。

**Q: 怎么区分5MΩ和30MΩ型号？**
A: 寄存器内容相同。可以写入 6,000,000Ω：5MΩ型号返回异常码 0x03，30MΩ型号正常输出（测试后记得写回0Ω）。

**Q: 支持Modbus RTU吗？**
A: 不支持，仅支持Modbus TCP。

**Q: 如何恢复出厂网络设置？**
A: 向 0x0116 写入 0x0002，再向 0x011F 写入 0x0001 重启。

**Q: 如何通过Modbus重启设备？**
A: 向 0x011F 写入 0x0001，或向 0x0116 写入 0x1000。设备先发送响应再重启。
