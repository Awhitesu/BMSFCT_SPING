# 电阻卡 Modbus TCP 使用说明

## 1. 概述

本电阻卡提供 6 路独立可编程电阻通道，通过以太网 Modbus TCP 协议远程设置阻值、读取状态和修改网络参数。

| 项目 | 参数 |
|------|------|
| 通道数 | 6（CH1–CH6） |
| 阻值范围 | 0 Ω – 1,500,000 Ω（1.5 MΩ） |
| 设置步进 | 10 Ω（阻值必须为 10 的整数倍） |
| 上电初始阻值 | 全部通道 0 Ω |
| 通信接口 | 10/100M 以太网，Modbus TCP |

## 2. 快速开始

1. 将电脑网口与电阻卡接入同一网段，电脑 IP 设为 `192.168.1.x`（x ≠ 10）。
2. 用任意 Modbus TCP 客户端连接 `192.168.1.10:502`。
3. 用功能码 **0x10** 向寄存器 `0x0000` 写入 2 个寄存器，即可设置 CH1 阻值。

例：设置 CH1 = 100,000 Ω（`100000 = 0x000186A0`）

```
地址 0x0000 写入 0x0001   (高16位)
地址 0x0001 写入 0x86A0   (低16位)
```

## 3. 通信参数

| 项目 | 说明 |
|------|------|
| 默认 IP 地址 | 192.168.1.10 |
| 默认子网掩码 | 255.255.255.0 |
| 默认网关 | 192.168.1.1 |
| TCP 端口 | 502 |
| 单元标识符（Unit ID） | 任意值均可，设备不校验，响应原样返回 |
| 最大连接数 | **1**。新连接建立时，设备会主动断开旧连接 |
| 支持功能码 | 0x03、0x04、0x06、0x10 |
| 单次读取上限 | 125 个寄存器 |
| 单次写入上限 | 123 个寄存器 |
| 字节序 | 寄存器内大端；32 位数值按"高 16 位在前、低 16 位在后"存放 |

> 由于只允许 1 个连接，请勿同时用多个上位机/调试工具连接同一块电阻卡，否则会互相踢下线。

## 4. 寄存器总表

功能码 0x03 与 0x04 读取的是同一组寄存器，结果相同。

| 地址 | 名称 | 读写 | 说明 |
|------|------|------|------|
| 0x0000 – 0x000B | CH1–CH6 阻值 | 读/写 | 每通道 2 个寄存器，见 4.1 |
| 0x000C – 0x000F | 保留 | — | 访问返回异常码 0x02 |
| 0x0100 | 系统状态 | 只读 | 0x0001 = 就绪 |
| 0x0101 | 设备 ID | 只读 | 0x5254（ASCII "RT"） |
| 0x0102 | 固件版本 | 只读 | 0x0102 = V1.2（高字节主版本，低字节次版本） |
| 0x0103 | 通道使能 | 读/写 | 位 0–5 对应 CH1–CH6，见 4.2 |
| 0x0104 | 总线状态 | 只读 | 位 0：低阻控制总线正常；位 1：高阻控制总线正常 |
| 0x0110 – 0x0115 | 网络参数 | 读/写 | IP、子网掩码、网关，见 4.3 |
| 0x0116 | 网络控制 | 读/写 | 保存配置、恢复默认、重启，见 4.3 |
| 0x011F | 软件重启 | 写 | 写 1 立即重启 |

> 标注"只读"的寄存器请勿写入。

### 4.1 通道阻值寄存器（0x0000 – 0x000B）

| 通道 | 高 16 位地址 | 低 16 位地址 |
|------|-------------|-------------|
| CH1 | 0x0000 | 0x0001 |
| CH2 | 0x0002 | 0x0003 |
| CH3 | 0x0004 | 0x0005 |
| CH4 | 0x0006 | 0x0007 |
| CH5 | 0x0008 | 0x0009 |
| CH6 | 0x000A | 0x000B |

换算公式：

```
阻值(Ω) = (高16位 << 16) | 低16位
高16位  = 阻值 >> 16
低16位  = 阻值 & 0xFFFF
```

**写入规则**

- 阻值必须在 0 – 1,500,000 Ω 之间，且为 10 Ω 的整数倍。
- 写入成功后阻值立即生效。
- 读回的是最近一次成功写入的设定值。

**推荐用 0x10 一次写入高、低两个寄存器。**

用 0x06 分两次写时，设备每写一个寄存器就会把它和另一半的**当前值**拼成阻值，并立即执行。中间值可能不合法，导致这次写入被拒绝。

> 例：CH1 当前为 10 Ω（高=0x0000，低=0x000A），目标为 100,000 Ω（高=0x0001，低=0x86A0）。
> 先用 0x06 写高 16 位 0x0001，设备拼出的阻值为 `0x0001000A = 65546 Ω`。它不是 10 的整数倍，返回异常码 0x04，高 16 位也**不会**被写入。

如果只能用 0x06，请保证每次拼出的中间值都合法。阻值不超过 65,535 Ω 时高 16 位恒为 0，只写低 16 位即可。

**批量设置**：用 0x10 从 0x0000 起连续写 12 个寄存器，可一次设置全部 6 个通道。如果其中某个通道失败，设备返回异常，所有寄存器都不会更新，但排在前面的通道可能已经切换。出现异常后，请重新写入全部通道。

### 4.2 通道使能寄存器（0x0103）

- 某一位写 0：对应通道立即切到最大阻值（约 1.67 MΩ，所有电阻全部接入），相当于"断开"。
- 禁用后，阻值寄存器保持原值，不随之变化。
- 恢复通道：重新写入该通道的阻值寄存器即可。
- 读取：返回最近一次写入的值（只保留低 6 位），上电默认 0x003F。

### 4.3 网络参数寄存器（0x0110 – 0x0116）

| 地址 | 内容 | 编码 |
|------|------|------|
| 0x0110 | IP 地址高 16 位 | `IP[0] << 8 \| IP[1]` |
| 0x0111 | IP 地址低 16 位 | `IP[2] << 8 \| IP[3]` |
| 0x0112 | 子网掩码高 16 位 | 同上 |
| 0x0113 | 子网掩码低 16 位 | 同上 |
| 0x0114 | 网关高 16 位 | 同上 |
| 0x0115 | 网关低 16 位 | 同上 |
| 0x0116 | 网络控制 | 位定义见下表 |

例：IP `192.168.1.50` → 0x0110 = `0xC0A8`，0x0111 = `0x0132`。

**网络控制寄存器 0x0116 位定义**

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | APPLY_CONFIG | 写 1：把 0x0110–0x0115 中的参数保存到 Flash |
| 1 | RESTORE_DEFAULTS | 写 1：恢复默认网络参数并保存到 Flash |
| 8 | REBOOT_REQUIRED | 只读：1 = 配置已保存，重启后生效 |
| 12 | SOFTWARE_RESET | 写 1：立即重启 |

常用写入值：

| 写入值 | 作用 |
|--------|------|
| 0x0001 | 仅保存配置 |
| 0x1001 | 保存配置并重启 |
| 0x1002 | 恢复默认配置并重启 |
| 0x1000 | 仅重启 |

**注意事项**

- 写 0x0110–0x0115 只是暂存参数，不会立即改变网络设置，必须再写 0x0116 保存，并重启后才生效。
- 设备会校验参数：IP 不能是 0.0.0.0 或 255.255.255.255，子网掩码必须是连续的 1。参数不合法时**不会**保存，但写入请求仍正常响应。
- 只保存、不重启时，可以读 0x0116 检查位 8：为 1 表示保存成功。
- 配置掉电保存，断电重启后仍然有效。

## 5. 修改 IP 地址的操作步骤

1. 用当前 IP 连接设备。
2. 用 0x10 向 0x0110 起连续写入 6 个寄存器：新 IP、子网掩码、网关。
3. 向 0x0116 写 `0x0001` 保存，然后读 0x0116，确认位 8 = 1。
4. 向 0x0116 写 `0x1000`（或向 0x011F 写 1）重启。
5. 等设备重启完成后，用新 IP 重新连接。

第 3、4 步可以合并：直接向 0x0116 写 `0x1001`。但设备会立即重启，无法通过位 8 确认是否保存成功；重启后如果新 IP 连不上，请用原 IP 再试。

> **忘记 IP 时**：可用配套工具 `Tools/ip_config_tool.py` 在网段内搜索设备。

## 6. 软件重启

- 向 0x011F 写 `1`，或向 0x0116 写 `0x1000`，设备约 0.5 秒后重启。
- 重启命令**收不到 Modbus 响应**，客户端会看到超时或连接断开，这是正常现象。请在重启后重新连接。
- 重启后各通道阻值恢复为 0 Ω。

## 7. 异常响应

请求非法时，设备返回异常响应：功能码最高位置 1（如 0x03 → 0x83），后跟 1 字节异常码。

| 异常码 | 含义 | 常见原因 |
|--------|------|----------|
| 0x01 | 非法功能码 | 使用了 0x03/0x04/0x06/0x10 以外的功能码 |
| 0x02 | 非法数据地址 | 地址超出 0x0000–0x011F；访问保留地址 0x000C–0x000F；数量为 0 或超限；0x10 的字节数与数量不匹配 |
| 0x03 | 非法数据值 | 阻值大于 1,500,000 Ω；请求报文长度不足 |
| 0x04 | 从站设备故障 | 阻值不是 10 Ω 的整数倍；内部控制总线通信失败 |

> 报文超过 260 字节，或 MBAP 长度字段非法时，设备会直接断开连接，不返回异常响应。

## 8. 报文示例

以下均为十六进制。MBAP 头依次为：事务号(2) 协议号(2) 长度(2) 单元号(1)。

**设置 CH1 = 100,000 Ω（0x10）**

```
请求: 00 01 00 00 00 0B 01  10 00 00 00 02 04 00 01 86 A0
响应: 00 01 00 00 00 06 01  10 00 00 00 02
```

**读取 CH1 阻值（0x03）**

```
请求: 00 02 00 00 00 06 01  03 00 00 00 02
响应: 00 02 00 00 00 07 01  03 04 00 01 86 A0      → 0x000186A0 = 100000 Ω
```

**读取 6 个通道阻值（0x03，12 个寄存器）**

```
请求: 00 03 00 00 00 06 01  03 00 00 00 0C
```

**阻值超范围的异常响应**

```
响应: 00 04 00 00 00 03 01  90 03
```

## 9. 代码示例

### 9.1 Python（pymodbus 3.x）

```python
from pymodbus.client import ModbusTcpClient

DEVICE_IP = "192.168.1.10"

def split32(value):
    return [(value >> 16) & 0xFFFF, value & 0xFFFF]

client = ModbusTcpClient(DEVICE_IP, port=502)
client.connect()

# 设置 CH1 = 100000 Ω（0x10 一次写高低两个寄存器）
client.write_registers(0x0000, split32(100000))

# 一次设置全部 6 个通道
values = [0, 1000, 10000, 100000, 500000, 1500000]
regs = []
for v in values:
    regs += split32(v)
client.write_registers(0x0000, regs)

# 读取全部通道阻值
rr = client.read_holding_registers(0x0000, count=12)
if not rr.isError():
    for ch in range(6):
        hi, lo = rr.registers[ch * 2], rr.registers[ch * 2 + 1]
        print(f"CH{ch + 1}: {(hi << 16) | lo} Ω")

# 读取设备信息
info = client.read_holding_registers(0x0100, count=5)
if not info.isError():
    r = info.registers
    print(f"状态: 0x{r[0]:04X}  设备ID: 0x{r[1]:04X}  固件: V{r[2] >> 8}.{r[2] & 0xFF}")

client.close()
```

**修改 IP 地址**

```python
from pymodbus.client import ModbusTcpClient

def ip_regs(ip):
    a, b, c, d = (int(x) for x in ip.split("."))
    return [(a << 8) | b, (c << 8) | d]

client = ModbusTcpClient("192.168.1.10", port=502)
client.connect()

regs = ip_regs("192.168.1.50") + ip_regs("255.255.255.0") + ip_regs("192.168.1.1")
client.write_registers(0x0110, regs)       # 写入新 IP / 掩码 / 网关
client.write_register(0x0116, 0x0001)      # 保存到 Flash

ctrl = client.read_holding_registers(0x0116, count=1).registers[0]
if ctrl & 0x0100:
    print("保存成功，正在重启...")
    try:
        client.write_register(0x0116, 0x1000)  # 重启（不会收到响应）
    except Exception:
        pass
else:
    print("保存失败，请检查参数是否合法")

client.close()
```

### 9.2 C#（EasyModbus）

```csharp
using EasyModbus;

var client = new ModbusClient("192.168.1.10", 502);
client.Connect();

// 设置 CH2 = 100000 Ω（0x10 写 2 个寄存器）
uint target = 100000;
client.WriteMultipleRegisters(2, new int[] { (int)(target >> 16), (int)(target & 0xFFFF) });

// 读取 CH2 阻值
int[] v = client.ReadHoldingRegisters(2, 2);
uint resistance = ((uint)v[0] << 16) | (uint)v[1];
Console.WriteLine($"CH2: {resistance} Ω");

client.Disconnect();
```

## 10. 常见问题

| 现象 | 处理方法 |
|------|----------|
| 无法连接 | 检查网线和网口指示灯；确认电脑与设备在同一网段；确认防火墙放行 TCP 502 端口 |
| 连接经常被断开 | 检查是否有其他程序同时连接设备（只支持 1 个连接） |
| 写阻值返回 0x04 | 确认阻值是 10 的整数倍；用 0x06 分两次写时，确认中间值合法（建议改用 0x10） |
| 写阻值返回 0x03 | 阻值超过 1,500,000 Ω |
| 读寄存器返回 0x02 | 读取范围跨入了保留地址 0x000C–0x000F，或超出了 0x011F |
| 改 IP 后连不上 | 确认已经重启；确认电脑与新 IP 在同一网段；可用 `Tools/ip_config_tool.py` 搜索设备 |
| 0x0104 不等于 0x0003 | 内部控制总线异常，阻值可能无法正确设置，请联系维护人员 |
