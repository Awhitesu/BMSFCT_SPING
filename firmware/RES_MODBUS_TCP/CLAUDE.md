## 项目概览

这是一个基于STM32F407VET6的RN-EOL可编程电阻板卡项目，实现通过继电器阵列的精确电阻控制，并通过Modbus TCP协议提供以太网接口。该项目创建了一个支持0Ω到5,000,000Ω范围（软件限幅）、1kΩ分辨率的单通道可编程电阻系统。

## 构建系统

本项目使用PlatformIO作为构建系统：

## 架构概览 ✨ V1.0 新架构

### 硬件架构
系统实现了一个基于继电器控制的单通道可编程电阻板卡，包含以下关键组件：

#### 继电器控制架构
- **控制方式**: 18路继电器直接GPIO控制
- **驱动芯片**: ULN2803A达林顿管阵列
- **电阻配置**: 4档位二进制加权 (1kΩ/10kΩ/100kΩ/1MΩ)
- **阻值范围**: 0Ω - 5,000,000Ω (5MΩ，软件限幅)
- **分辨率**: 1kΩ
- **控制逻辑**: GPIO高电平 → 继电器吸合 → 电阻接入电路

#### 继电器电阻档位
| 档位 | 基数电阻 | 双倍电阻 | 继电器 | 最大组合 |
|------|----------|----------|--------|----------|
| 1kΩ  | 1kΩ      | 2kΩ×4    | K1,K2,K3,K4,K5 | 9kΩ |
| 10kΩ | 10kΩ     | 20kΩ×4   | K6,K7,K8,K9,K10 | 90kΩ |
| 100kΩ| 100kΩ    | 200kΩ×4  | K11,K12,K13,K14,K15 | 900kΩ |
| 1MΩ  | 1MΩ      | 2MΩ×2    | K16,K17,K18 | 5MΩ |

**理论组合总阻值**: 9kΩ + 90kΩ + 900kΩ + 5MΩ = 5.999MΩ（软件限幅到 5MΩ）

- **电阻规格**:
  - 阻值范围: 0Ω 到 5,000,000Ω (5MΩ，软件限幅)
  - 分辨率: 1kΩ

  - `Relay_PrintStatus()` - 打印继电器状态信息
- **算法特性**:

  - 从大到小遍历继电器选择最优组合
  - 自动误差计算和补偿显示
  - 完整的参数验证和错误处理

#### 新电阻控制接口 (`src/resistor_control_new.c/h`)

- **系统特性**:
  - 单通道架构，保持8通道寄存器兼容性
  - 阻值范围: 0Ω 到 5,000,000Ω (5MΩ，软件限幅)
  - 分辨率: 1kΩ
- **主要接口**:
  - `Resistor_New_Init()` - 初始化新的电阻控制系统
  - `Resistor_New_SetChannelValue()` - 设置通道阻值
  - `Resistor_New_GetChannelValue()` - 读取通道阻值
  - `Resistor_New_PrintSystemInfo()` - 打印完整系统信息
- **兼容性**:
  - 保持与原Modbus TCP协议完全兼容
  - 寄存器映射结构更新，支持新设备ID和网络功能
  - 设备ID更新为"RNEOL_RES_5M"(RN-EOL电阻板卡5M型号，13字符存储在8个16位寄存器)

#### Modbus TCP服务器 (`src/modbus_tcp.c/h`)
- **功能**: 完整的Modbus TCP协议实现，适配新硬件
- **服务器特性**:
  - TCP服务器端口502
  - 最多4个并发客户端连接
  - 完整的连接管理和错误处理
  - 设备ID更新为"RNEOL_RES_5M" (13字符，存储在8个16位寄存器0x0101-0x0108)
- **支持的Modbus功能码**:
  - 0x03 - 读取保持寄存器 (读取通道电阻值)
  - 0x04 - 读取输入寄存器 (读取通道电阻值)
  - 0x06 - 写入单个寄存器 (设置单通道电阻值)
  - 0x10 - 写入多个寄存器 (批量设置电阻值)
- **寄存器映射**:
  - 0x0000-0x0001: CH1电阻值 (32位分高低16位)
  - 0x0002-0x000F: CH2-CH8保留 (兼容性)
  - 0x0100-0x0109: 系统信息 (状态、设备ID、固件版本) - 只读
  - 0x0110-0x0116: 网络配置 (IP地址、子网掩码、网关、保存控制)
  - 0x011F: 系统控制 (软件重启)
- **主要接口**:
  - `Modbus_TCP_Init()` - 初始化Modbus TCP服务器
  - `Modbus_TCP_Start()` - 启动TCP服务器监听
  - `Modbus_TCP_Process()` - 处理Modbus请求和响应
  - `Modbus_Update_Registers()` - 同步硬件状态到寄存器

#### 网络配置模块 (`src/network_config.c/h`)
- **功能**: 动态网络参数配置和Flash存储
- **核心特性**:
  - IP地址、子网掩码、网关地址动态设置
  - 配置参数Flash存储，掉电保存
  - 启动时自动加载保存的网络配置
  - 配置有效性验证和校验和保护
- **Flash存储**: 使用STM32F407 Flash扇区11 (0x080E0000, 128KB)
- **主要接口**:
  - `NetworkConfig_Init()` - 初始化网络配置模块
  - `NetworkConfig_SetIPAddress()` - 设置IP地址
  - `NetworkConfig_Save()/Load()` - 配置保存和加载
  - `NetworkConfig_RestoreDefaults()` - 恢复默认配置
- **Modbus集成**: 通过寄存器0x0110-0x0116提供完整的网络配置接口，支持手动保存和软件重启

#### 系统控制功能
- **网络配置保存 (0x0116)**: 手动触发将当前网络配置保存到Flash
- **软件重启 (0x011F)**: 通过Modbus TCP远程触发系统软件重启
- **优雅重启**: 系统先发送Modbus响应，再执行重启操作
- **状态保护**: 重启前自动保存关键状态信息

### 关键设计原则
1. **直接GPIO控制**: 摒弃复杂的I²C架构，改为可靠的GPIO控制
2. **贪心算法优化**: 使用高效的组合算法实现最优电阻值
3. **向后兼容**: 保持原有Modbus协议结构，同时扩展新功能
4. **网络可访问性**: 完整的Modbus TCP协议实现，支持远程控制
5. **实时响应**: 继电器状态与Modbus寄存器实时同步
6. **多客户端支持**: 同时支持最多4个Modbus TCP客户端连接
7. **硬件抽象**: STM32 HAL用于外设管理

### 继电器电阻组合算法

#### 贪心算法实现
系统使用贪心算法计算最优继电器组合：

**算法步骤**:
1. 将所有继电器按电阻值从大到小排序
2. 初始化剩余目标阻值为用户设置的目标值
3. 遍历排序后的继电器列表：
   - 如果继电器阻值 ≤ 剩余目标阻值，则启用该继电器
   - 从剩余目标阻值中减去已选继电器阻值
4. 重复直到剩余目标阻值为0或无法继续组合

**继电器排序** (从大到小):
```
2MΩ (K8, K12) → 1MΩ (K4) → 200kΩ (K7, K11, K15, K18) → 100kΩ (K3)
→ 20kΩ (K6, K10, K14, K17) → 10kΩ (K2) → 2kΩ (K5, K9, K13, K16) → 1kΩ (K1)
```

**阻值计算**:
```
实际阻值 = Σ(已启用继电器的电阻值)
误差 = 实际阻值 - 目标阻值
```

**精度特性**:
- 最大理论误差: < 1kΩ
- 分辨率: 1kΩ (物理限制)
- 计算复杂度: O(n) where n=18

### PHY芯片适配说明

**硬件配置**: RN-EOL板卡使用KSZ8863RLLI PHY芯片，通过RMII接口连接。

**驱动架构**:
- 文件名为 `ksz8863rlli.c/h`，只保留KSZ8863RLLI支持
- 通过MIIM读取端口PHY ID，确认KSZ8863RLLI端口PHY
- 固定配置MAC为100Mbps全双工
- 使用PA3作为PHY硬件复位引脚

#### KSZ8863RLLI特性
- **接口模式**: RMII
- **时钟要求**: 25MHz晶振
- **LED指示**: 支持Link/Activity和Speed状态LED
- **自适应**: 支持10/100Mbps自适应
- **功耗**: 低功耗设计
- **PHY地址扫描**: 支持0-31地址自动扫描识别
- **扩展功能**: WOL唤醒、PAD驱动强度配置、Slew Rate控制

#### 硬件连接
| 功能 | MCU引脚 | 说明 |
|------|---------|------|
| REF_CLK | PA1 | 50MHz参考时钟 |
| MDIO | PA2 | 管理数据接口 |
| MDC | PC1 | 管理时钟 |
| CRS_DV | PA7 | 载波侦听/数据有效 |
| RXD0 | PC4 | 接收数据0 |
| RXD1 | PC5 | 接收数据1 |
| TX_EN | PB11 | 发送使能 |
| TXD0 | PB12 | 发送数据0 |
